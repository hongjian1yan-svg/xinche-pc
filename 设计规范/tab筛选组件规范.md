# PC端UI设计规范（列表过滤组件）

## 1. 顶部 Tab 分类（Tabs）
用于切换不同业务状态下的数据列表。

### 视觉参数
* **组件样式**：采用矩形色块选项卡。
* **尺寸**：每个 Tab 宽度 **90px**，高度 **40px**。
* **状态设置**：
    * 包含项：全部、在库车、待入库、待上架、已上架、待出库、已出库。
* **背景色**：
    * 非激活状态：浅灰色背景 `#f9fafb`。
    * 激活状态：浅灰色背景 **#F2F2F2**。
* **文字颜色**：均为 **#303133**（14px）。
* **边框**：每个 Tab 带有除底部外的 `1px` 实线边框，颜色为 **#e3e4e5**。

---

## 2. 筛选项容器（Filter Container）
承载复杂的搜索条件，采用 **多行表单布局**。

### 布局规范
* **布局**：多行表单布局，距离主内容容器上下 20px，左右 12px。
* **容器边距**：内容距背景上下 **20px**，左右 **12px**；**左对齐展示**。
* **间距**：与上方 Tab 区域无间距，无需分割线。
* **背景色**：矩形背景色 **#F2F2F2**。
* **下方内容间距**：距离下方表格内容 **40px**。
* **操作按钮布局**：
    * **位置**：强制在筛选项内容的第二行（或最末行）单独展示。
    * **对齐**：整体左对齐，起始位置需设置 **92px** 的左边距（计算逻辑：80px 标签宽度 + 12px 固定间距）。
    * **间距**：按钮水平间隔 **12px**。
    * **间距优化**：操作按钮所在的表单项底部外边距（margin-bottom）需设为 **0**，以确保内容距背景底部的视觉间距严格保持为 **20px**。

### 元素规范
* **表单项结构**：水平布局（Inline-flex）。
    * **Label 宽度**：统一设为 **80px**，文字右对齐，距控件固定 **12px**。
    * **控件高度**：输入框、选择框及查询/重置按钮统一为 **40px**（Large 尺寸）。
* **控件类型**：
    * **输入框 (Input)**：车牌号、商户名称、车架号、RFID。
    * **选择框 (Select)**：所属市场、车辆状态、能源类型、冻结状态、质押状态、检测状态、是否评估、指标管控状态、黑名单车、车身类型、车辆类型、开票状态。
    * **日期选择 (Date Picker)**：时间区间（datetimerange）。
* **核心操作按钮**：
    * **查询按钮**：`type="primary"`，绑定 `:icon="Search"`，高度 40px，文字居中。
    * **重置按钮**：`type="default"`，绑定 `:icon="Refresh"`，高度 40px，文字居中。

---

## 3. 业务操作区（Business Actions）
* **批量操作**：如“批量入库”，采用 `danger` 类型（红色）以突出提示风险。
* **功能工具**：如“导出”，采用 `primary` 浅色风格，文字为白色。

---

## 4. 交互逻辑
* **Tab 切换**：点击不同 Tab，应触发接口重新请求对应状态的数据。
* **查询触发**：点击”查询”按钮后执行检索；回车键应绑定查询事件。
* **重置行为**：点击”重置”需恢复所有下拉菜单至默认值，清空所有输入框内容。

---

## 5. Tab 联动逻辑（筛选条件驱动 Tab 动态显示）

当页面存在影响 Tab 可见性的筛选条件时，Tab 列表需根据筛选值**动态显示/隐藏**。

### 规则定义
* **联动触发时机**：筛选项（如「冻结来源」）值发生变化时，立即重新计算可见 Tab 列表，无需点击查询。
* **自动回退规则**：若筛选条件变化导致当前激活的 Tab 被隐藏，系统自动将激活 Tab 回退至列表第一项（通常为默认状态 Tab），同时重置分页至第 1 页。
* **重置还原**：点击「重置」按钮后，筛选条件清空，Tab 列表恢复完整显示。

### 冻结车列表示例

| 冻结来源筛选值 | 展示 Tab |
|------------|--------|
| 全部（未选择） | 已冻结 / 已解冻 / 待审核 / 审核通过 / 审核驳回 |
| 手动冻结 | 已冻结 / 已解冻 / 待审核 / 审核通过 / 审核驳回 |
| 金融质押冻结 | 已冻结 / 已解冻 |
| 合同到期冻结 | 已冻结 / 已解冻 |
| 金融管控冻结 | 已冻结 / 已解冻 |

### Vue 3 实现示例

```javascript
// 根据筛选条件计算可见 Tab
const visibleTabs = computed(() => {
  const src = filters.value.source
  if (!src || src === 'manual') return ALL_TABS
  return ALL_TABS.slice(0, 2) // 只保留「已冻结」「已解冻」
})

// 筛选来源变化时：检查当前 Tab 是否仍可见，否则自动回退
const handleSourceChange = () => {
  currentPage.value = 1
  const names = visibleTabs.value.map(t => t.name)
  if (!names.includes(activeTab.value)) {
    activeTab.value = 'frozen' // 回退至默认 Tab
  }
}
```
