## 一、页面整体结构

本页面采用系统标准三区布局（侧边栏 + 顶部状态栏 + 主内容区），参见[页面整体布局规范.md]。

主内容区内部为上下两个独立模块，顺序固定：金融公司在上，资金渠道在下。

```
┌──────────────────────────────────────────────┐
│  模块标题：金融公司                             │
│  操作按钮区（+ 新增金融公司）                    │
│  筛选条件区                                    │
│  金融公司数据表格 + 分页                        │
├──────────────────────────────────────────────┤
│  （模块间距 20px）                              │
├──────────────────────────────────────────────┤
│  模块标题：资金渠道                             │
│  操作按钮区（+ 新增渠道）                        │
│  筛选条件区                                    │
│  资金渠道数据表格 + 分页                        │
└──────────────────────────────────────────────┘
```

> 本页面无 Tab 分类栏。

---

## 二、模块标题样式

两个模块标题样式统一，采用大标题 + 下划线分割线形式：

```css
.section-title {
  font-size: 16px;
  font-weight: 600;
  color: #303133;
  padding-bottom: 12px;
  margin-bottom: 20px;
  border-bottom: 1px solid #EBEEF5;
}
```

两个模块之间整体间距 **20px**。

### 5.2 表单布局

- Label 右对齐，宽度 **80px**
- 控件宽度：`100%`
- 表单项垂直间距：**22px**

### 5.3 表单字段规范

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 所属市场 | `el-select` | 是 | 超管可选所有市场，新增时默认空置显示"请选择市场"；市场管理员只读显示本市场 |
| 公司名称 | `el-input` | 是 | placeholder="请输入公司名称"，不限制字数 |
| 负责人 | `el-input` | 是 | placeholder="请输入负责人" |
| 负责人电话 | `el-input` | 是 | placeholder="请输入负责人电话"，手机号格式校验 |
| 证件号码 | `el-input` | 否 | placeholder="请输入负责人证件号码" |
| 备注 | `el-input` type="textarea" | 否 | placeholder="请输入备注信息，50字以内"，maxlength=50，show-word-limit，rows=3 |
| 图片信息 | 图片上传 | 否 | 虚线边框上传区域，内含 `+` 图标，支持上传一张图片 |

### 5.4 弹窗底部操作

标题栏与底部操作区均**不显示分割线**。

| 按钮 | 位置 | 属性 | 显示条件 |
|------|------|------|----------|
| 取消 | 左 | 默认样式 | 始终显示 |
| 继续新增资金渠道 | 中 | 蓝色描边（`type="primary" plain`） | 仅**新增**时显示；编辑时隐藏（`v-if="!isEdit"`） |
| 确定 | 右 | `type="primary"`，提交中显示 `:loading="submitting"` | 始终显示 |

**「继续新增资金渠道」交互：**
1. 点击后先执行与「确定」相同的校验与保存逻辑
2. 校验/保存成功后，关闭当前弹窗，自动弹出「新增资金渠道」弹窗
3. 新增资金渠道弹窗中「所属市场」和「所属金融公司」自动预填刚创建的公司，两个字段均禁用（`disabled`）不可修改

**⑤ 车辆评估选项**

| 属性 | 值 |
|------|---|
| 组件 | `el-radio-group` |


tooltip 触发方式：`trigger="click"`，placement="top"。

**⑥ 评估平台**（仅"自动评估"时通过 `v-if` 渲染）

| 校验提示 | `请至少选择一个评估平台` |

**⑥ 渠道说明**

| 属性 | 值 |
|------|---|
| 组件 | `el-input` type="textarea" |
| placeholder | 请输入渠道说明，方便商户了解该渠道特点 |
| 必填 | 否 |

信息卡片：背景 `#f8f9fb`，边框 `1px solid #ebeef5`，圆角 `6px`，内边距 `12px 16px`，文字居中。

### 8.2 资金渠道删除确认弹窗

| 按钮 | 属性 |

## 十、权限控制的视觉处理

| 场景 | 处理方式 |
|------|---------|
| 无新增权限 | 对应模块的新增按钮不渲染（`v-if`） |
| 无编辑权限 | 操作列编辑按钮不渲染（`v-if`） |
| 无删除权限 | 操作列删除按钮不渲染（`v-if`） |
| 操作日志 | 始终渲染，无权限限制 |
| 查看详情 | 始终渲染，无权限限制 |

统一使用 `v-if` 控制显隐，不使用 `disabled`。

## 十一、关联改动：市场配置页面新增字段

### 11.1 金融订单编号前缀

**位置：** 市场配置页面 → 金融系统设置模块，紧跟"金融系统"开关下方。

**可编辑状态（未产生订单时）：**

```html
<el-form-item label="金融订单编号前缀" required>
  <el-input
    v-model="form.orderPrefix"
    placeholder="请输入2～6位大写字母，如：JHJR"
    maxlength="6"
    show-word-limit
    style="width: 240px"
  />
  <div class="field-tip">用于生成该市场的金融订单编号，设置后不可修改</div>
</el-form-item>
```

**只读状态（已产生订单后）：**
- 输入框添加 `disabled` 属性
- 右侧展示锁形图标（`Lock`，#C0C4CC）
- hover 锁形图标时 tooltip 提示："已有金融订单，编号前缀不可修改"

校验规则：

| 校验项 | 提示文案 |
|--------|---------|
| 必填 | 请输入金融订单编号前缀 |
| 格式（仅大写字母A-Z） | 编号前缀仅支持大写字母（A-Z） |
| 长度（2～6位） | 编号前缀长度须在 2～6 位之间 |
| 唯一性 | 该编号前缀已被其他市场使用，请更换 |

### 11.2 市场核价自动评估开关

**位置：** 市场配置页面 → 金融系统设置模块，金融订单编号前缀字段下方。

**组件：** `el-switch`，默认关闭状态。

**字段标签：** 市场核价自动评估

**说明文字（开关下方）：**

```css
.field-tip {
  font-size: 12px;
  color: #909399;
  margin-top: 4px;
  line-height: 1.5;
}
```

说明文字内容：开启后，资金渠道配置中可选择自动评估方式（需与第三方评估平台完成合作后开启）
