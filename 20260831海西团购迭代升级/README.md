## PC 已实现范围

### 团购商品

- 菜单名：团购优惠券管理；所属市场正式名：厦门海西名车MALL。
- 团购类型：原价商品、团购优惠商品；两类均为线下核销商品。
- 原价商品只配置第一步“团购基本信息”；团购优惠商品继续配置第二步“团购核销设置”。
- 第一步包含商品原价、可选商品团购价（仅团购优惠商品）、核验服务商、数量限制、上架与下架时间等已确认字段；原价商品不展示商品团购价；列表、详情与新增弹窗均不展示满减限制。
- 核验服务商默认开启且必填，支持名称搜索与多选；关闭时隐藏选择区域且不校验；列表与详情需展示，未配置为「—」。
- 数量限制选“有限”后展示张输入框。
- 列表与详情不展示「车况套餐」。
- 商品详情采用右侧抽屉，第一步字段归入“卡券信息”，第二步字段归入“分配核销”。
- 「查询数据导出」导出列表全部列内容。

### 优惠券配置

- 适用业务：原价商品、团购优惠商品、车况查询、停车缴费；新增表单必填「所属市场」。
- 团购优惠商品绑定后显示“与团购优惠叠加”，默认不叠加；其他业务不显示该项。
- 仅停车缴费展示“停车券领取限制”；停车缴费「绑定对象」列表/详情显示「—」。
- 优惠类型为抵扣时：已配置团购价的商品校验团购价；仅配置原价的商品校验原价。
- 保留「使用说明」（500 字以内）；列表/详情删除「购买限制」「核销限制」。
- 「领取用户类型 / 领取会员限制」与「用户类别 / 会员限制」两套独立配置、独立展示。
- 筛选字段：优惠券名称、优惠券类型（及所属市场、状态、适用业务、绑定对象、创建时间）。
- 优惠券详情采用右侧抽屉展示列表信息及使用资格限制。
- 列表操作：团购在待上架/上架中含「编辑信息 / 提前下架 / 操作日志」，已下架仅「删除」；优惠券含「编辑 / 下架·上架 / 删除 / 操作日志」。
- 下架不影响已购未核销团购、已领未用优惠券；用户限制含注册时间 / 注册满 / 认证日期附加项。

### 列表约束

- 团购列表和优惠券列表字段以 PRD 第 6 节为准；未收到明确需求时，不得隐藏、删除或调整既有字段。
- 两张列表的列宽已收窄，超宽内容在表格区域横向查看。

## 小程序范围摘要

- 首页含会员福利、停车缴费、车况查询入口；会员福利含“免费领券”“超值团购”两个 Tab。
- 团购详情展示优惠后实付价与删除线原价；实付 0 元展示“免费”。
- 停车缴费、车况查询及线下核验产品的领券与使用入口规则详见 PRD。

## 编辑约定

- 仅维护原生 HTML、CSS、JavaScript，不创建 Vue、React、Vite 等工程或依赖文件。
- 预览中的服务商和列表数据均为模拟数据；接入真实接口、服务商主数据或持久化不在当前范围。
- 修改业务字段、规则或交互时，同时更新 PRD；不要基于推测增加字段、选项、校验或文案。
- 修改页面后需实际打开预览，验证关键状态、相邻布局和脚本无报错。
