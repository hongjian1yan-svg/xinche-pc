# PC端UI设计规范（页面整体布局）

## 一、 布局结构

所有管理后台页面采用统一的三区布局：**侧边栏 + 顶部状态栏 + 主内容区**。

```
┌─────────┬──────────────────────────────────┐
│         │         顶部状态栏 (60px)          │
│ 侧边栏  ├──────────────────────────────────┤
│ (180px) │                                  │
│         │         主内容区                  │
│         │       (flex: 1, 自适应)           │
└─────────┴──────────────────────────────────┘
```

---

## 二、 各区域规范

### 1. 侧边栏 (Sidebar)
详见 [./侧边栏组件规范.md](./侧边栏组件规范.md)，关键参数：
* 宽度：固定 **180px**，高度充满视口（`height: 100vh`）
* 背景色：**#FFFFFF**，右侧 `box-shadow: 2px 0 8px rgba(29,35,41,0.05)`

### 2. 顶部状态栏 (Header)
* **高度**：固定 **60px**
* **背景色**：**#FFFFFF**，底部 `border-bottom: 1px solid #f0f0f0`
* **左侧**：市场名称，字号 **14px**，颜色 **#333333**，字重 **600**，格式为【市场全称】
* **右侧**（从左至右排列）：
    * 角色切换器（演示环境使用）
    * 头像（圆形，**30×30px**）
    * 用户名（**16px**，**#000000**，字重 600）
    * 角色标签（背景 **#d0e2f2**，宽度自适应，高 **20px**，圆角 **4px**，文字 **12px #1d2c4f**）
    * 下拉箭头（背景 **#f3f5fc**，**20×20px**，圆角 **4px**）

### 3. 主内容区 (Main Content)
* **外边距**：距侧边栏、顶部栏、右侧、底部均为 **15px**（`padding: 15px`）
* **背景色**：外层 **#f2f4f5**，内容容器 **#f9fafb**
* **内容容器内边距**：上下左右 **20px 12px**
* **最小宽度**：建议整体页面不低于 **1200px**

---

## 三、 主内容区内部结构

业务列表页面的主内容区，从上至下依次为：

```
┌─────────────────────────────────────────┐
│  Tab 筛选栏（高度 40px）                  │
├─────────────────────────────────────────┤
│  筛选条件区（背景 #F2F2F2，padding 20px） │
├─────────────────────────────────────────┤
│  （距上方间距 40px）                       │
│  数据表格                                │
│                                         │
│  分页组件（右对齐，距表格 20px）            │
└─────────────────────────────────────────┘
```

* **Tab 筛选栏** 紧贴筛选条件区顶部，无间距、无分割线
* **筛选区** 与 **表格** 之间间距固定 **40px**

## 四、 Vue 3 代码结构示例

```html
<el-config-provider :locale="zhCn">
  <el-container class="layout-container">

    <!-- 侧边栏 -->
    <el-aside width="180px" class="sidebar">
      <div class="logo">...</div>
      <el-menu ...>...</el-menu>
    </el-aside>

    <el-container direction="vertical">

      <!-- 顶部状态栏 -->
      <el-header height="60px" class="top-header">
        <div class="market-info">【市场名称】</div>
        <div class="user-profile">...</div>
      </el-header>

      <!-- 主内容区 -->
      <el-main class="main-content">
        <div class="content-body">
          <!-- Tab 筛选 -->
          <div class="tab-filter-container">...</div>
          <!-- 筛选条件 -->
          <div class="search-filter-container">...</div>
          <!-- 表格 + 分页 -->
          <div class="view-container">...</div>
        </div>

        <!-- 详情抽屉（按需） -->
        <el-drawer ...>...</el-drawer>
        <!-- 操作弹窗（按需） -->
        <el-dialog ...>...</el-dialog>
      </el-main>

    </el-container>
  </el-container>
</el-config-provider>
```

```css
.layout-container { height: 100vh; background-color: #f2f4f5; min-width: 1200px; }
.main-content     { padding: 15px; background: #f2f4f5; overflow: auto; }
.content-body     { background-color: #f9fafb; min-height: 100%; padding: 20px 12px; }
.view-container   { margin-top: 40px; }
```
