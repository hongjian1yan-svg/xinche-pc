# AI:design —— 二手车市场官网（PC 门户站）设计规范

> 版本：v1.1（2026-09-28）——增量同步 09-24~09-28 预览页已落地实现：圆角体系、顶部语言按钮（顶搜移至首页）、详情页四操作按钮与「立即联系」下拉浮层、咨询车况弹层、价格三语口径（俄文双币 / тыс. ₽ 统一 / 区间标签取百）、首页搜索条与汇率卡；表单/分页等尺寸按实测修正。所有数值以 `css/style.css`、`js/` 及浏览器 getComputedStyle 实测为准。  
> 适用对象：**面向消费者/车商的二手车市场官网（PC 门户站）**，即本目录下 `shouye / buycar / cardetail / sellcars / news-list / news-detail / about / success` 8 页模板及其衍生市场站。  
> **与公司内部「信车 PC 端管理系统」设计规范的关系**：两者是**互相独立的两套规范**。信车管理系统是 ElementUI 后台（表单密集型、侧边栏布局、面向内部员工），其规范不适用于对外官网；本规范沉淀的是门户站（内容展示型、顶部导航 + 版心布局、面向 C 端用户）的设计约定。两套规范共用的仅有：信车蓝主色 #004199、ElementUI 2.15.14 图标字体库。官网**不引入** ElementUI 组件库运行时，只复用其图标字体与色彩语言。

## 1. 画布与版心

| 项 | 规范值 | 说明 |
|---|---|---|
| 设计稿宽度 | ≥ 1440px | 出稿按 1440 画布；页面 `min-width: 1200px`，更窄出横向滚动，不做响应式断点 |
| 版心 | **1200px 居中**（`.wrap`） | 全站所有分区内容都收在版心内 |
| 顶栏高度 | 80px | Logo 区（定宽 320px）+ 导航 + 语言按钮同高；**顶栏已无搜索框**（移至首页内容区，见 4.16） |
| Banner 高度 | 480px（首页）；卖车页 hero 不设固定高（上下 padding 60px、由表单卡内容撑开，实测约 800px，原 660px 口径作废） | 通栏背景、内容收版心 |
| 页脚 | 通栏深灰 #444，上区 padding 44px 0 36px，下条 52px | |
| 分区节奏 | 灰底分区上下 padding 约 44–60px；白底分区标题居中时 padding 40px 0 8px | 相邻分区「白-灰-白」交替形成节奏 |
| 栅格 | 非严格栅格，按内容分栏：首页买车区 `flex + gap 24px`（左面板自适应 + 右卖车卡 336px）；列表 4 列卡 `gap 20px`；详情页 图 520px + 信息自适应，`gap 30px`；新闻页 主列自适应 + 侧栏 300px，`gap 30px` | 栏间距实测：20 / 24 / 30px 三档，就近取用 |

## 2. 色彩系统（信车蓝体系，2026-09-18 起）

全部色值以 `css/style.css` 的 `:root` CSS 变量管理，**禁止散落硬编码**。

| 变量 | 色值 | 使用场景 |
|---|---|---|
| `--primary` | **#004199 信车蓝** | 主要按钮（首页搜索、快速卖车、立即提交、咨询车况）、Tab 选中态文字+下划线、导航 hover/当前页、重要文字链接（查看更多、选中排序、已选条件、电话强调）、筛选选中项底色、分页选中、缩略图选中描边、悬浮栏 hover 底色、轮播选中圆点、分区标题装饰条/箭头、立即联系浮层行标题 |
| `--primary-dark` | #00337a | 主按钮 hover/active（比主色深一档） |
| `--primary-light` | #e8eef8 | 浅蓝辅助底：卖车侧卡底、表单卡头底、优势图标圆底、下拉菜单 hover 底、次级按钮 hover 底、已选条件标签底 |
| `--primary-line` | #c9d8ef | 浅蓝描边：已选条件标签边框 |
| `--price` | #f43636 价格红 | **仅**车价数字、划线原价保留灰、错误提示边框/文字、热门榜前三序号 |
| `--bg-gray` | #f5f5f5 | 分区灰底、面包屑底、参数盒底、报告盒底 |
| `--text-dark` | #111111 | 标题、当前导航、卡片车型名 |
| `--text` | #333333 | 正文 |
| `--muted` | #999999 | 辅助信息：日期、meta、表单提示、筛选行标签 |
| `--border` | #e8e8e8 | 卡片/面板/输入框外描边 |
| `--footer-bg` / `--footer-bottom` | #444 / #3a3a3a | 页脚主体 / 版权条 |

**对比度规则**：#004199 在白底与 #f5f5f5 底上对比度约 10:1，浅底小号蓝字（≥12px）直接用 `--primary` 原色，**不得**用 tint 色作文字色；白字置于 #004199 按钮上对比充分，无需调整。价格红、灰块分区、白底不因换色改变。

**占位图渐变**：Banner/新闻缩略/商户卡等纯色或渐变占位统一走 #004199 系（如 `linear-gradient(115deg,#002a5e,#004199,#4d7dc0)`）；车辆照片占位保留多色（模拟实车颜色多样性），不强制收敛。

## 4. 组件规范

### 4.0 圆角体系（2026-09-28 定稿，以 style.css 末段兜底规则为准）
- **12px**：所有卡片与独立内容面板——车源卡、首页买车面板、卖车侧卡、商户卡、汇率卡、悬浮栏及其浮层、二维码占位、主图框、价格块、车辆档案卡、车辆图片、报告盒、商户条、卖车表单卡、优势卡、新闻盒、关于图集、咨询车况弹层、「立即联系」浮层。
- **8px**：常规按钮（`.btn` 全族）、裸 `button/input/select/textarea`、el-select 触发器与语言按钮 caret 所在控件、筛选选中胶囊（`.fr-opt.on`）、卖车表单卡内控件（由 Element 4px 档统一升 8px）。
- **保持小圆角档（局部小控件/组合件，不在 8px 兜底覆盖范围）**：语言按钮与其下拉菜单 4px、`.sf-field/.iq-field` 基础控件块 4px（卖车卡除外）、自定义价格输入与「确定」按钮 4px、el-select 下拉面板 4px、分页 2px（el-pager 规格）、勾选框/卖点标签/已选条件标签 2px、分享行按钮（sl-btn）4px。
- **保持圆形（50%）**：品牌字标（58px）、商户 logo（56px）、汇率国旗（44px）、轮播圆点（12px）与商户轮播点（10px）、成功页大图标（88px）。
- **连接形态**：首页组合搜索内部输入/按钮圆角 0（外框 8px 收口）；Banner 贴边箭头外侧 8px、内侧 0。
- **车辆列表卡片**：2026-09-28 起移除灰色描边（`border:0`），仅保留 12px 圆角轮廓，层次靠 hover 上浮投影与留白表达；其余带描边面板不变。

### 4.1 顶部导航（全站公共）
- 高 80px 白底，底部 1px #f0f0f0 分隔线。
- Logo 区：**定宽 320px**（为三语公司全称留稳定位，右距 14px）+ 44px 主色字标 + 16px 加粗公司名；原「Logo 右距 46px」口径作废。
- 导航项：5 项**定宽 128px 居中**（切语言栏位不动）；17px/#111/行高 80px，en 15px、ru 13px 适配长词；**hover** 变 `--primary`；**当前页** `--primary` + 底部 3px 主色下划线（距底 16px、左右各缩进 26px，hover 同样滑出）。
- **语言按钮**（导航右侧，`margin-left:auto` 贴版心右缘）：栏位**定宽 128px**；触发框 128×38px、白底 1px #dcdfe6、**4px 圆角**，内容 = **20×20px 语言 SVG 图标**（`img/lang/中文|英文|俄文.svg`，随当前语言切换）+ 图标右距 8px + 12px 语言名 + 12px `el-icon-arrow-down`；hover 主色字、边框 #c0c4cc。下拉菜单 `min-width:128px`、距触发框 6px、白底 1px #e4e7ed + 4px 圆角 + `0 2px 12px` 阴影；项 13px `padding 9px 14px`，hover 浅蓝底主色字，当前语言主色加粗。
- 原顶搜（262×38px）已移除，改为首页内容区组合搜索条（见 4.16）。

### 4.2 Banner 轮播
- 高 480px，淡入切换 0.6s，自动轮播；左右箭头 44×66px 半透明深色底（rgba(31,45,61,.28)），hover 加深；贴屏幕边侧圆角外 8px、内 0。

### 8.6 价格展示口径（2026-09-28 定稿，代码实现于 js/i18n.js + js/rates.js）

| 场景 | zh | en | ru |
|---|---|---|---|
| 车辆售价（列表卡/详情现价/弹层车卡） | 按「万」（如 `12.8万`，卡片 20px bold 红 + 「万」13px） | **仅美元**：`$` + 千分位取整（`$ + Math.round(万×10000/6.876)` 按 en-US 千分位） | **双币并排：卢布为主 + 美元为辅**：主价 `тыс. ₽` 红色大字；辅价走 `.pc-usd`（13px `--muted`、左距 8px；详情现价 34px 上下辅价 16px/左距 10px，弹层车卡 b 14px 上下辅价 12px/左距 6px，随字号上下文适配）；基线对齐、各自 `white-space:nowrap` |
| 新车指导价（diOldPrice） | 单币种万 | 单币种美元 | **单币种卢布**（不走双币，勿在 fmtPriceDualHTML 上扩散） |
| 价格区间筛选标签（priceLabel） | `X万以下 / X-Y万 / X万以上` | 单币种：`Under $Xk / $X–Yk / Over $Xk`（千为单位取整） | 单币种 **тыс. ₽、数值四舍五入到百位、无小数**：`до 300 тыс. ₽ / 300 – 800 тыс. ₽ / от 2 300 тыс. ₽`（空格千分位；允许与中文档位不逐一对应，YAN 2026-09-28 确认） |
| 生成笔记复制文本（fmtPriceDualText） | 万 | 美元 | 双币用 ` / ` 分隔纯文本 |

- **卢布统一单位「тыс. ₽」**（2026-09-28，废除「млн ₽」写法）：千卢布 = 万 × 10000 × 11.59 ÷ 1000；**1 位小数（整数省略小数位）、逗号小数点（俄式）、整数部分空格千分位**。例：7万 → `811,3 тыс. ₽`；32.6万 → `3 778,3 тыс. ₽`（`fmtRubThs`）。
- 英文价格不用「k」缩写于售价（仅区间标签用 $Xk）；售价 `$` 前缀、en-US 千分位。
- 筛选区「价格」行标题与胶囊行**顶对齐**（`.filter-row align-items:flex-start` + `.fr-label line-height:30px`，2026-09-28 实测确认）。
- 首页汇率展示卡与价格换算同源同汇率，不另设汇率。
