# PC端UI设计规范（表格组件）

## 1. 视觉参数
* **表头样式**：
    * 背景色：**#F5F7FA**。
    * 文字颜色：**#909399**。
    * 字号：14px，加粗。
    * 文字对齐：**居中**。
* **行高规范**：默认行高设定为 **54px**（区间 48px - 60px）。
* **边框与分割线**：采用 1px 实线边框，颜色为 **#EBEEF5**。
* **背景色**：
    * 奇偶行：默认不开启斑马纹，悬停（Hover）背景色为 **#F5F7FA**。

## 2. 功能布局
* **操作列**：建议固定在右侧（`fixed="right"`），确保在横向滚动时操作可见。
    * **布局**：Flex 换行排列，每行最多显示两个按钮。
    * **按钮样式**：操作列统一使用以下三种样式，禁止引入其他颜色类型（见下方规范）。
    * **间距**：按钮之间水平/垂直间隔均为 **8px**。
    * **对齐**：按钮组在单元格内水平居中对齐。

### 操作列按钮三种样式规范

| 样式 | Element Plus 属性 | 视觉表现 | 适用操作 |
|-----|-----------------|--------|--------|
| **蓝色填充** | `type="primary"` | 蓝底白字 | 主操作：查看详情、审核通过 |
| **蓝色描边** | `type="primary" plain` | 白底蓝字蓝边 | 次要操作：操作日志、车辆解冻等 |
| **红色描边** | `type="danger" plain` | 白底红字红边 | 明确否定/删除操作：审核驳回、删除 |

> **原则**：操作列不使用 `success`、`warning`、`info` 等其他颜色，保持视觉简洁统一。

### 操作列按 Tab 状态的按钮规则

不同 Tab 下操作列展示的按钮固定如下，与行数据的来源类型解耦：

| Tab | 操作列按钮 |
|-----|----------|
| **已冻结** | 查看详情（蓝色填充）/ 车辆解冻（红色描边，按来源+角色权限判断）/ 操作日志（蓝色描边） |
| **已解冻** | 查看详情（蓝色填充）/ 操作日志（蓝色描边） |
| **待审核** | 查看详情（蓝色填充）/ 审核通过（蓝色描边）/ 审核驳回（红色描边）/ 操作日志（蓝色描边） |
| **审核通过** | 查看详情（蓝色填充）/ 操作日志（蓝色描边） |
| **审核驳回** | 查看详情（蓝色填充）/ 操作日志（蓝色描边） |

### Vue 3 代码实现示例

```html
<el-table-column label="操作" width="180" fixed="right" align="center">
  <template #default="scope">
    <div class="operation-btns">
      <!-- 待审核 -->
      <template v-if="activeTab === 'pending'">
        <el-button type="primary" size="small" @click="showDetail(scope.row)">查看详情</el-button>
        <el-button type="primary" size="small" plain @click="openAudit(scope.row, 'approved')">审核通过</el-button>
        <el-button type="danger"  size="small" plain @click="openAudit(scope.row, 'rejected')">审核驳回</el-button>
        <el-button type="primary" size="small" plain @click="openLog(scope.row)">操作日志</el-button>
      </template>
      <!-- 审核通过 / 审核驳回 -->
      <template v-else-if="activeTab === 'approved' || activeTab === 'rejected'">
        <el-button type="primary" size="small" @click="showDetail(scope.row)">查看详情</el-button>
        <el-button type="primary" size="small" plain @click="openLog(scope.row)">操作日志</el-button>
      </template>
      <!-- 已冻结 -->
      <template v-else-if="activeTab === 'frozen'">
        <el-button type="primary" size="small" @click="showDetail(scope.row)">查看详情</el-button>
        <el-button v-if="canUnfreeze(scope.row)" type="danger" size="small" plain @click="openUnfreeze(scope.row)">车辆解冻</el-button>
        <el-button type="primary" size="small" plain @click="openLog(scope.row)">操作日志</el-button>
      </template>
      <!-- 已解冻 -->
      <template v-else-if="activeTab === 'released'">
        <el-button type="primary" size="small" @click="showDetail(scope.row)">查看详情</el-button>
        <el-button type="primary" size="small" plain @click="openLog(scope.row)">操作日志</el-button>
      </template>
    </div>
  </template>
</el-table-column>
```

  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 8px;
}
.operation-btns :deep(.el-button) { margin: 0 !important; }
```
* **分页组件 (Pagination)**：
    * 位置：位于表格右下方。
    * 间距：距离表格顶部间距为 **20px**。
    * 控件：包含总条数、页码、每页显示数量切换。

## 3. 交互逻辑
* **内容溢出**：单元格内容超出宽度时，默认显示省略号，鼠标悬停显示气泡（Tooltip）。
* **数据加载**：表格切换页面或刷新时，需开启 Loading 状态。

## 4. 使用场景
* 适用于展示结构化业务数据。当单页数据超过 20 条时，必须配置分页组件。

## 附录：分页组件规范 (Pagination)

### 1. 视觉布局
分页组件必须位于表格区域的 **右下角**，与表格主体保持 `20px` 的垂直间距。

* **核心属性**：
    * `background`: 必须设置为 `true`（开启页码按钮背景色）。
    * `layout`: 统一使用 `"total, sizes, prev, pager, next, jumper"`。
    * `page-sizes`: 默认提供 `[10, 20, 50, 100]` 四个选项。

### 2. 代码实现示例 (Vue 3 + Element Plus)
AI 在生成表格页面时，应在表格下方自动补齐以下结构：

```html
<div class="pagination-container">
  <el-pagination
    v-model:current-page="currentPage"
    v-model:page-size="pageSize"
    :page-sizes="[10, 20, 50, 100]"
    :background="true"
    layout="total, sizes, prev, pager, next, jumper"
    :total="totalCount"
    @size-change="handleSizeChange"
    @current-change="handleCurrentChange"
  />
</div>
---
