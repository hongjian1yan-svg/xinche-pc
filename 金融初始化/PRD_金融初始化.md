> 所属系统：智慧车市  
> 所属模块：库容管理  
> 文档版本：v1.2  
> 状态：待评审

## 一、背景与目标

### 1.1 背景

平台金融系统在使用前需要完成两项基础配置：金融公司信息录入、资金渠道配置。现有系统中：

- 金融公司管理已作为独立菜单存在，支持基本的增删改查
- 资金渠道配置依赖后端工程师直接操作数据库添加渠道名称，效率低、维护成本高
- 两个配置项分散在不同入口，没有体现"先配置公司、再配置渠道"的业务依赖关系

### 1.2 目标

1. 将金融公司管理与资金渠道管理合并为「金融初始化」统一入口
2. 在前端提供完整的资金渠道配置能力，消除对后端数据库操作的依赖
3. 建立"金融公司 → 资金渠道"的归属关系，使业务层级清晰可维护
4. 页面上下分区布局，引导用户先配置金融公司，再配置资金渠道

### 1.3 不在本次范围内

- 临时出场默认限制：该配置项属于市场级全局设置，保留在市场配置页面，不纳入本次需求
- 旧版资金渠道数据迁移：现有三个开通金融业务的市场，由运营人员在新功能上线后手动完成重新配置；配置完毕并确认业务正常后，由研发从市场配置页面移除旧的资金渠道配置模块
- 金融订单编号前缀：属于市场配置页面的关联改动，详见第八章
- 市场核价自动评估开关：属于市场配置页面的关联改动，详见第八章

## 二、信息架构

### 2.1 导航变更

原有「金融公司管理」菜单直接替换为「金融初始化」，不新增菜单项：

```
库容管理
├── 二次复核列表
├── 申请审核列表
├── 商户质押订单
├── 库融订单
├── 盘库列表
├── 临时出场列表
├── 金融初始化        ← 原「金融公司管理」替换
└── 金融管控车管理
```

### 2.2 业务层级关系

```
市场（A市场）
└── 金融公司（如：泸州银行）
    └── 资金渠道（如：标准质押产品）
        ├── 渠道名称
        ├── 放款比例
        ├── 车辆评估选项
        └── 评估平台（自动评估时必填）
```

## 三、页面整体结构

页面采用上下分区布局，两个模块在同一页面内顺序排列：

```
┌──────────────────────────────────────────────┐
│  【金融公司】模块标题                            │
│  筛选区                                        │
│  + 新增金融公司                                 │
│  金融公司数据表格 + 分页                         │
├──────────────────────────────────────────────┤
│  【资金渠道】模块标题                            │
│  筛选区                                        │
│  + 新增渠道                                    │
│  资金渠道数据表格 + 分页                         │
└──────────────────────────────────────────────┘
```

两个模块之间使用分割线或间距区分，各自拥有独立的筛选区、操作按钮和数据表格。

| 操作 | 样式 | 权限 |
|------|------|------|
| 编辑 | 蓝色描边 | 需有编辑权限 |

| 操作日志 | 蓝色描边 | 无限制 |

**删除校验规则：**
- 删除前校验该渠道是否有**正在进行中的质押订单**
- 有正在进行中的质押订单时，不允许删除，提示：
  > "该资金渠道存在进行中的质押订单，无法删除。"
- 无正在进行中的质押订单时，允许删除；删除后历史质押订单中的资金渠道记录保持不变，不受影响

**弹窗参数：**

| 属性 | 值 |
|------|---|

**表单字段：**

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|

| 所属金融公司 | 下拉选择 | 是 | 来源：当前市场金融公司列表 |
| 放款比例 | 数字输入 + `%` 后缀 | 是 | 范围 1～100，最多两位小数 |
| 车辆评估选项 | 单选按钮组 | 是 | 自动评估 / 人工评估；受市场开关控制，见下方 |
| 评估平台 | 多选下拉 | 条件必填 | 仅"自动评估"时显示；选项后端动态配置 |
| 渠道说明 | 多行文本 | 否 | 用于向商户解释该渠道的特点和适用场景；最多100字 |

**车辆评估选项联动规则：**
- 选择"自动评估"后，下方显示评估平台多选字段；评估平台默认无选中项，由用户手动选择
- 选择"人工评估"后，评估平台字段隐藏

**自动评估受市场开关控制：**
- 当前市场"市场核价自动评估"开关**开启**时：自动评估选项正常可选
- 当前市场"市场核价自动评估"开关**关闭**时：
  - 自动评估选项置灰不可点击
  - 弹窗打开时默认选中"人工评估"（无论历史配置）
  - 用户点击置灰的"自动评估"时，气泡提示："暂未开启自动评估，请联系管理员"
  - 开关重新开启后，弹窗默认仍选中"人工评估"，由市场管理员手动修改

**底部操作：**

| 按钮 | 属性 |
|------|------|
| 取消 | 默认样式 |
| 保存 | `type="primary"`，提交中显示 loading |

**唯一性校验：** 同市场下渠道名称重复时，字段下方提示：

> "该渠道名称已存在，请更换"

**所属金融公司无数据时：** 下拉无选项，底部提示：

> "当前市场暂无金融公司，请先在上方完成金融公司配置"

## 六、交互规则与异常处理

### 6.1 表单校验时机

- 每个字段失焦（onBlur）时触发单字段校验
- 点击确定/保存时触发全字段校验
- 唯一性校验在提交时由后端返回

### 6.2 删除确认弹窗（通用）

点击删除时，弹出二次确认：

| 属性 | 值 |
|------|---|
| 宽度 | `width="420px"`，`align-center` |
| 图标 | `WarningFilled`，#E6A23C，40px |
| 内容 | 确认删除？+ 名称信息卡片 + "删除后不可恢复" |
| 按钮 | 取消（默认）/ 确认删除（`type="danger"`） |

### 6.3 评估平台接口异常

多选框显示禁用状态，提示：

> "评估平台数据加载失败，请刷新页面重试"

### 6.4 网络/接口异常

所有操作接口异常时，统一通过 Message 组件在页面顶部提示错误信息。

## 八、关联改动：市场配置页面

### 8.1 金融订单编号前缀

**背景：** 金融订单编号由"前缀 + 日期 + 当日序号"组成，例如 `JHJR20260610001`。前缀标识订单所属市场，编号规则维持市场级别，不跟随金融公司或资金渠道变化。现有系统中该前缀由后端工程师手动维护，本次需提供前端配置入口。

**改动位置：** 市场配置页面 → 金融系统设置模块，新增"金融订单编号前缀"配置项。

| 属性 | 说明 |
|------|------|
| 字段名称 | 金融订单编号前缀 |
| 组件类型 | 单行文本输入框 |
| 必填条件 | 开启金融系统时必填 |
| 格式要求 | 2～6位大写字母（A-Z） |
| 唯一性 | 平台内所有市场不可重复 |
| 修改限制 | 产生第一笔金融订单后字段变为只读，tooltip 提示"已有金融订单，编号前缀不可修改" |
| 权限 | 仅超级管理员可编辑 |

### 8.2 市场核价自动评估开关

**背景：** 自动评估依赖第三方评估平台（收费服务），需业务方与平台方谈妥合作后方可开启。通过市场级开关控制该市场是否可使用自动评估功能。

**改动位置：** 市场配置页面 → 金融系统设置模块，新增"市场核价自动评估"开关。

| 属性 | 说明 |
|------|------|
| 字段名称 | 市场核价自动评估 |
| 组件类型 | 开关（Switch） |
| 默认状态 | 关闭 |
| 权限 | 仅超级管理员可操作 |

**开关关闭时的影响范围：**

| 影响位置 | 表现 |
|---------|------|
| 新增/编辑渠道弹窗 - 自动评估选项 | 置灰不可点击，默认选中"人工评估" |
| 点击置灰的自动评估选项 | 气泡提示："暂未开启自动评估，请联系管理员" |

**开关重新开启时：**
- 编辑弹窗默认选中"人工评估"，由市场管理员手动修改各渠道配置

### 8.3 开通金融系统引导顺序

1. 超管在市场配置中开启金融系统开关
2. 填写"金融订单编号前缀"（必填）
3. 按需开启"市场核价自动评估"开关
4. 保存市场配置
5. 前往「金融初始化」页面创建金融公司
6. 在资金渠道模块创建资金渠道
7. 金融系统正式可用

## 九、旧版数据处理说明

### 9.1 当前现状

市场配置页面金融系统设置中，现有"资金渠道"配置模块（含渠道名称、放款比例、评估方式）。目前共三个市场开通金融业务，存在部分旧渠道数据。

### 9.2 迁移方式

采用**人工重新配置**方式，不做自动化数据迁移：

1. 新功能上线后，由运营/管理员在「金融初始化」页面为三个市场逐一配置金融公司和渠道数据
2. 配置完成并确认金融业务运行正常后
3. 由研发将市场配置页面中的旧"资金渠道"配置模块移除

### 9.3 临时出场默认限制

该字段不纳入本次迁移，继续保留在市场配置页面，作为市场级全局设置维护。
