# PC端UI设计规范（Element Plus适配）

## 侧边栏导航（Sidebar / Menu）

### 1. 规范定义
侧边栏用于展示系统的多级菜单结构，提供全局导航功能。支持菜单的展开、收起以及当前选中状态的高亮显示。

### 2. 视觉参数
* **整体尺寸**：宽度固定为 **180px**。
* **Logo 区域**：
    * **区域高度**：**90px**。
    * **Logo 图片**：尺寸为 **40px * 40px**，引用 `src/logo.png`。
    * **文字样式**：字号 **20px**，颜色 **#0444a6**，字重常规体。
* **背景色值**：默认采用 **#FFFFFF**（亮色模式）。
* **菜单项**：
    * **高度**：一级菜单与二级菜单项均为 **56px**。
    * **字号**：统一为 **14px**。
    * **常规颜色
    * **：次要文字色 **#66798c**。
    * **图标**：采用线性图标，与文字间距 **8px**。
* **二级菜单（Sub-menu Item）**：
    * **表现形式**：不显示图标，仅展示文字。
* **激活状态（Active）**：
    * **背景色**：使用 **#48528e** 作为选中标识。
    * **文字色**：选中项文字变更为反白 **#FFFFFF**。
* **悬停状态（Hover）**：
    * **背景色**：使用 **#f2f7ff** 作为悬停反馈。
    * **内容颜色**：文字与图标均变更为 **#409eff**。
    * **适用范围**：同时适用于一级菜单项与二级菜单项。

### 3. 交互规则
* **Hover**：鼠标悬停在菜单项上时，背景色产生视觉反馈。
* **点击（Click）**：点击父级菜单展开/折叠子列表；点击子菜单进行页面跳转，并同步更新选中状态。
* **折叠逻辑**：支持将侧边栏收起至 **64px**，仅保留图标显示。

### 4. 使用场景
* 适用于 SaaS 系统、中后台管理界面的全局一级及二级导航。

### 5. 禁用场景
* 当页面属于单一流程（如注册引导、全屏看板）时，应隐藏侧边栏以释放空间。

### 6. Design Skill 可复用性
* **高度适配**：侧边栏应充满整个视口高度（`height: 100vh`）。
* **层级控制**：组件层级（Z-index）应高于内容区，确保滚动时不被覆盖。
* **内容溢出**：若菜单项过多，应配置内部滚动条，并隐藏原生滚动条以保持美观。
