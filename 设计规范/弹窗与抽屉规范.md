# PC端UI设计规范（弹窗与抽屉）

## 一、 详情抽屉 (Drawer)

### 1. 使用场景
点击表格操作列「查看详情」时，从页面**右侧**以抽屉形式滑出，展示单条记录的完整信息。不跳转新页面，保留列表上下文。

### 2. 视觉参数
* **方向**：`direction="rtl"`（从右侧滑入）
* **宽度**：`size="50%"`，在 1920px 屏幕下约 960px，在 1366px 屏幕下约 683px
* **内部内边距**：Element Plus 默认，内容区额外 `padding: 0 4px 40px`

### 3. 内容区结构（业务详情页）

从上至下分为若干 Section，每个 Section 之间间距 **28px**：

| 序号 | 模块 | 说明 |
|-----|------|------|
| 1 | **车辆基本信息卡片** | 车辆图片 + 车型名称 + 标签（来源、车牌号） |
| 2 | **冻结信息** | `el-descriptions` 展示关键字段 |
| 3 | **申请解冻照片** | 仅特定来源展示，无照片时显示空态占位 |
| 4 | **来源特有子模块** | 根据业务来源条件渲染（v-if） |
| 5 | **冻结记录** | `el-timeline` 时间轴，按时间倒序 |

### 4. Section 标题样式
```css
.section-title {
  font-size: 14px;
  font-weight: bold;
  color: #303133;
  margin-bottom: 14px;
  padding-left: 10px;
  border-left: 4px solid #48528e; /* 左侧装饰条，使用系统辅色 */
  line-height: 16px;
}
```

### 5. 车辆基本信息卡片样式
```css
.detail-header-card {
  display: flex;
  gap: 20px;
  padding: 16px;
  background: #f8fafc;
  border-radius: 8px;
  border: 1px solid #eef0f3;
  margin-bottom: 24px;
}
.detail-main-img {
  width: 180px;
  height: 135px;
  border-radius: 6px;
  flex-shrink: 0;
}
```

### 6. 空态占位（无照片）
```css
.photo-empty {
  height: 80px;
  background: #f8f9fb;
  border: 1px dashed #dcdfe6;
  border-radius: 4px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: #c0c4cc;
  font-size: 13px;
}
```

### 7. 固定宽度详情抽屉（大尺寸内容场景，可选变体）
当详情内容信息密度高、需要横向展示多组表格/多列信息时（如金融公司详情：机构信息 + 资金渠道子表格），标准 `size="50%"` 可能不足以容纳内容，允许使用以下固定宽度变体：

* **实现方式**：不使用 `el-drawer`，改用自定义 `position: fixed; top:0; right:0; height:100vh` 容器
* **宽度**：固定 `1130px`（不随屏幕宽度变化）
* **关闭按钮**：位于抽屉外侧左边缘，`40×40px`，主题蓝背景，`border-radius: 4px 0 0 4px`，紧贴抽屉左侧
* **遮罩**：点击遮罩默认不关闭

> 两种抽屉方案二选一：常规详情（单栏信息为主）用 `size="50%"` 相对宽度；信息密度高、含子表格的详情用固定 1130px 方案。同一模块内同类详情页保持同一种方案，不要混用。

## 二、 操作确认弹窗 (Dialog — Confirm)

### 1. 使用场景
执行**不可逆或有风险**的操作前，弹出确认弹窗，如：车辆解冻、批量操作、删除等。根据是否需要展示目标对象详细信息，分为**完整卡片款**与**简洁款**两种，两者属性不可混用（如简洁款不能用大图标居中+加粗标题）。

### 2. 完整卡片款
适用场景：需要展示目标对象名称、关联数据量等信息供用户核对（如金融公司删除时需提示关联渠道数）。

* **宽度**：`width="420px"`，`align-center`（垂直居中）
* **内容**：警告图标（`WarningFilled`，`#E6A23C`，40px，居中）+ 加粗提示文案 + 目标对象信息卡片
* **底部按钮**：取消（默认）+ 确认（风险操作用 `type="danger"`，一般操作用 `type="primary"`）

信息卡片样式：
```css
.confirm-car-card {
  width: 100%;
  background: #f8f9fb;
  border: 1px solid #ebeef5;
  border-radius: 6px;
  padding: 12px 16px;
  text-align: center;
}
```

### 3. 简洁款
适用场景：仅需二次确认"是否执行"，不需要展示具体对象信息（如资金渠道删除、通用停用/删除确认）。

* **标题**：固定「提示」
* **宽度**：`width="380px"`，`align-center`，`:close-on-click-modal="false"`
* **内容**：横向一行布局，`display:flex; align-items:center; gap:8px`——警告图标（`WarningFilled`，`#E6A23C`，**18~22px**）在左，提示文案在右，垂直居中对齐
* **文案样式**：`font-size:14px`，`color:#303133`，`font-weight:400`（不加粗），`text-align:left`（左对齐，不居中）
* **底部按钮**：取消（默认）+ 确定（`type="primary"` 蓝色填充，文案固定为「确定」，不用「确认删除」等红色强调）

```css
.confirm-dialog { display: flex; align-items: center; gap: 8px; padding: 4px 0 8px; }
.confirm-tip { font-size: 14px; color: #303133; font-weight: 400; text-align: left; line-height: 1.5; }
```

> **选用依据**：被操作对象是否需要展示名称等关键信息供用户核对——需要用完整卡片款，不需要用简洁款。

## 三、 审核弹窗 (Dialog — Audit)

### 1. 使用场景
在「待审核」Tab 点击「审核通过」或「审核驳回」时触发，弹出审核信息确认弹窗。

### 2. 视觉参数
* **宽度**：`width="540px"`，`align-center`
* **标题**：随操作动态变化（`审核通过确认` / `审核驳回确认`）
* **内容**：`el-descriptions` 展示申请信息 + 审核意见/驳回原因输入框（Textarea，可选）
* **底部按钮**：取消（默认）+ 确认按钮（通过时 `type="success"`，驳回时 `type="danger"`）

### 3. 实现要点

```javascript
// 同一弹窗，通过 action 参数区分通过/驳回模式
const auditAction = ref('approved') // 'approved' | 'rejected'

const openAudit = (row, action) => {
  currentAuditRow.value = row
  auditAction.value = action
  auditForm.value = { remark: '' }
  auditVisible.value = true
}
```

```html
<el-dialog
  v-model="auditVisible"
  :title="auditAction === 'approved' ? '审核通过确认' : '审核驳回确认'"
  width="540px"
  align-center
>
  ...
  <template #footer>
    <el-button @click="auditVisible = false">取消</el-button>
    <el-button
      :type="auditAction === 'approved' ? 'success' : 'danger'"
      @click="handleAudit"
    >{{ auditAction === 'approved' ? '确认通过' : '确认驳回' }}</el-button>
  </template>
</el-dialog>
```

## 四、 操作日志弹窗 (Dialog — Log)

### 1. 使用场景
点击列表操作列「操作日志」时，弹出该记录的操作历史，以**表格**展示，不使用时间轴。

### 2. 视觉参数
* **标题**：固定「操作日志」；右上角提供关闭（×）
* **宽度**：约 `560px`（可按内容微调，建议 `540–640px`），`align-center`
* **遮罩**：点击遮罩默认不关闭，须通过关闭按钮或底部按钮关闭
* **内容**：中间为三列表格
* **底部按钮**：右对齐「取消」（默认）+「确定」（`type="primary"` 蓝色填充）

### 3. 表格字段（固定）

| 列名 | 说明 |
| --- | --- |
| 操作人 | 执行操作的账号姓名 |
| 操作介绍 | 操作动作说明，如「立即上架」「创建团购」「下架」等 |
| 操作时间 | 格式 `YYYY-MM-DD HH:mm:ss`，如 `2026-06-25 13:44:02` |

### 4. 表格样式
* 表头与单元格文字**居中**
* 表格外边框与单元格分隔线：`1px solid #ebeef5`
* 字号 `14px`；文字色 `#606266`
* 表头背景默认白色（不加灰底条），字重中等
* 单元格内边距约 `12px 10px`；长文案可折行（`word-break: break-all`）

```css
.log-dialog {
  width: 560px;
  border-radius: 2px;
  background: #fff;
  box-shadow: 0 2px 12px rgba(0, 0, 0, 0.12);
}
.log-dialog__header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 16px 20px 12px;
  font-size: 16px;
  font-weight: 500;
  color: #303133;
}
.log-dialog__body {
  padding: 4px 20px 8px;
}
.log-dialog__footer {
  display: flex;
  justify-content: flex-end;
  gap: 10px;
  padding: 12px 20px 16px;
}
.log-table {
  width: 100%;
  border-collapse: collapse;
  table-layout: fixed;
  font-size: 14px;
  border: 1px solid #ebeef5;
}
.log-table th,
.log-table td {
  padding: 12px 10px;
  border: 1px solid #ebeef5;
  text-align: center;
  color: #606266;
  word-break: break-all;
}
.log-table th {
  background: #fff;
  font-weight: 500;
}
```

### 5. 实现示例

```html
<el-dialog
  v-model="logVisible"
  title="操作日志"
  width="560px"
  align-center
  :close-on-click-modal="false"
>
  <el-table :data="logList" border style="width: 100%">
    <el-table-column prop="operator" label="操作人" align="center" />
    <el-table-column prop="action" label="操作介绍" align="center" />
    <el-table-column prop="time" label="操作时间" align="center" />
  </el-table>
  <template #footer>
    <el-button @click="logVisible = false">取消</el-button>
    <el-button type="primary" @click="logVisible = false">确定</el-button>
  </template>
</el-dialog>
```

> **注意**：历史若曾用 `el-timeline` 展示操作日志，新页面一律改用本表格方案；团购、优惠券等模块操作日志字段与样式保持一致。

## 五、 业务表单弹窗 (Dialog — Form / Step)

### 1. 使用场景
新增、编辑等需要填写多字段的业务配置（如「新增团购」「新增优惠券」「编辑信息」）。内容多、可分步时使用**分步表单弹窗**；字段较少时可单步。

### 2. 整体结构
从上至下固定为：

| 区域 | 说明 |
| --- | --- |
| 标题栏 | 左侧标题（如「新增团购」）；右侧关闭（×） |
| 步骤条（可选） | 居中展示步骤，如「1 团购基本信息 → 2 团购核销设置」；当前步主色高亮 |
| 表单内容区 | 可纵向滚动 |
| 底部操作栏 | 右对齐：取消 + 主操作（下一步 / 确定 / 上一步+确定） |

### 3. 视觉参数
* **宽度**：大表单默认约 `920px`（可按业务微调）
* **最大高度**：约 `92vh`；超出后内容区可滚动
* **圆角**：`4px`；白底；遮罩约 `rgba(0,0,0,.5)`
* **标题**：字号约 `18px`；底部分割线 `#EBEEF5`；内边距约 `20px 24px`
* **关闭按钮**：右上角，色 `#909399`
* **内容区内边距**：约 `18px 32px`（或 `24px`）
* **底栏**：顶部分割线；内边距约 `16px 24px`；按钮间距 `12px`
* **遮罩**：点击遮罩默认不关闭

### 4. 滚动条
* 弹窗内容可上下滚动，**不展示右侧滚动条滑块**（滚动仍可用鼠标滚轮 / 触控板）。
* 实现参考：`overflow: auto` + `scrollbar-width: none`；WebKit 下隐藏 `::-webkit-scrollbar`。

```css
.dialog {
  width: 920px;
  max-height: 92vh;
  overflow: auto;
  scrollbar-width: none;
  -ms-overflow-style: none;
  border-radius: 4px;
  background: #fff;
  box-shadow: 0 12px 32px 4px rgba(0, 0, 0, 0.04), 0 8px 20px rgba(0, 0, 0, 0.08);
}
.dialog::-webkit-scrollbar {
  width: 0;
  height: 0;
  display: none;
}
```

### 5. 步骤条
* 步骤数字圆形描边；当前步文字与描边为 `#409EFF`；未激活为 `#909399`
* 步骤之间用横线连接，线色 `#DCDFE6`

```css
.stepper {
  display: flex;
  align-items: center;
  justify-content: center;
  gap: 20px;
  padding: 12px 0 26px;
}
.step {
  display: flex;
  align-items: center;
  gap: 8px;
  color: #909399;
  font-size: 17px;
  font-weight: 600;
}
.step.active { color: #409eff; }
.step b {
  display: grid;
  place-items: center;
  width: 26px;
  height: 26px;
  border: 2px solid currentColor;
  border-radius: 50%;
  font-size: 14px;
}
.step-line {
  width: 140px;
  height: 2px;
  background: #dcdfe6;
}
```

### 6. 弹窗内表单布局
* **标签右对齐**；标签列宽约 `100–120px`
* **标签与控件顶部对齐**（`align-items: start`），不得相对整块控件垂直居中——尤其控件含说明文案、开关+搜索框、上传区等增高内容时（如「团购类型」「核验服务商」）
* 标签可设 `padding-top: 10px`，与首行控件文字视觉对齐
* 表单项垂直间距约 `22px`
* 必填星号：标签左侧，`#F56C6C`，间距 `4px`

```css
.form-field {
  display: grid;
  grid-template-columns: 120px minmax(0, 1fr);
  align-items: start;
  gap: 12px;
  margin-bottom: 22px;
}
.form-field > label {
  padding-top: 10px;
  line-height: 20px;
  text-align: right;
  color: #606266;
}
.form-field.required > label::before {
  margin-right: 4px;
  color: #f56c6c;
  content: '*';
}
```

### 7. 输入框与选择框边框统一
弹窗、筛选区的 **Select 触发器** 必须与 **Input** 使用同一套边框规范，禁止 Select 单独使用 inset `box-shadow` 描边导致视觉不一致：

| 状态 | 边框 |
| --- | --- |
| 默认 | `1px solid #DCDFE6`，圆角 `4px`，高度与表单 Input 一致（弹窗内常用 `40px`） |
| Hover | `#C0C4CC` |
| Focus / 展开 | `#409EFF`，可加淡蓝外阴影 `0 0 0 2px #ECF5FF` |

```css
.control,
.el-select__wrapper {
  height: 40px;
  padding: 0 12px;
  border: 1px solid #dcdfe6;
  border-radius: 4px;
  background: #fff;
  box-shadow: none;
}
.control:hover,
.el-select__wrapper:hover { border-color: #c0c4cc; }
.control:focus,
.el-select.open .el-select__wrapper {
  border-color: #409eff;
  box-shadow: 0 0 0 2px #ecf5ff;
}
```

### 8. 下拉收起
* 点击下拉面板或触发器以外的区域，下拉须收起（含带搜索的多选服务商选择器等）。
* 多选场景：在面板内连续勾选可不收起；点空白处再收起。

### 9. 编辑态
* 编辑弹窗结构、步骤与样式与对应「新增」弹窗保持一致。
* 仅业务允许修改的字段可编辑；其余字段只读展示（可降低透明度 / `pointer-events: none`）。

## 六、 通用规范

* **遮罩层**：点击遮罩默认**不关闭**弹窗（防止误触），须通过按钮关闭
* **弹窗层级**：Z-index 高于导航栏和内容区
* **滚动**：业务表单大弹窗可滚动但不显示滚动条滑块（见第五节）
* **表单对齐**：弹窗内标签与控件顶部对齐；输入框与选择框边框样式一致（见第五节）
* **国际化**：所有弹窗需在根节点配置 `<el-config-provider :locale="zhCn">` 以保证中文提示
