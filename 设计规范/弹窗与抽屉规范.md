# PC端UI设计规范（弹窗与抽屉）

## 一、 详情抽屉 (Drawer)

### 1. 使用场景
点击表格操作列「查看详情」时，从页面**右侧**以抽屉形式滑出，展示单条记录的完整信息。不跳转新页面，保留列表上下文。

### 2. 视觉参数
* **方向**：`direction="rtl"`（从右侧滑入）
* **宽度**：`size="50%"`，在 1920px 屏幕下约 960px，在 1366px 屏幕下约 683px
* **内部内边距**：Element Plus 默认，内容区额外 `padding: 0 4px 40px`

### 3. 内容区结构（业务详情页）

从上至下分为若干 Section，每个 Section 之间间距 **28px**：

| 序号 | 模块 | 说明 |
|-----|------|------|
| 1 | **车辆基本信息卡片** | 车辆图片 + 车型名称 + 标签（来源、车牌号） |
| 2 | **冻结信息** | `el-descriptions` 展示关键字段 |
| 3 | **申请解冻照片** | 仅特定来源展示，无照片时显示空态占位 |
| 4 | **来源特有子模块** | 根据业务来源条件渲染（v-if） |
| 5 | **冻结记录** | `el-timeline` 时间轴，按时间倒序 |

### 4. Section 标题样式
```css
.section-title {
  font-size: 14px;
  font-weight: bold;
  color: #303133;
  margin-bottom: 14px;
  padding-left: 10px;
  border-left: 4px solid #48528e; /* 左侧装饰条，使用系统辅色 */
  line-height: 16px;
}
```

### 5. 车辆基本信息卡片样式
```css
.detail-header-card {
  display: flex;
  gap: 20px;
  padding: 16px;
  background: #f8fafc;
  border-radius: 8px;
  border: 1px solid #eef0f3;
  margin-bottom: 24px;
}
.detail-main-img {
  width: 180px;
  height: 135px;
  border-radius: 6px;
  flex-shrink: 0;
}
```

### 6. 空态占位（无照片）
```css
.photo-empty {
  height: 80px;
  background: #f8f9fb;
  border: 1px dashed #dcdfe6;
  border-radius: 4px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: #c0c4cc;
  font-size: 13px;
}
```

## 二、 操作确认弹窗 (Dialog — Confirm)

### 1. 使用场景
执行**不可逆或有风险**的操作前，弹出确认弹窗，如：车辆解冻、批量操作等。

### 2. 视觉参数
* **宽度**：`width="420px"`，`align-center`（垂直居中）
* **内容**：警告图标（`WarningFilled`，`#E6A23C`，40px）+ 提示文案 + 目标对象信息卡片
* **底部按钮**：取消（默认）+ 确认（`type="primary"`）

### 3. 信息卡片样式
```css
.confirm-car-card {
  width: 100%;
  background: #f8f9fb;
  border: 1px solid #ebeef5;
  border-radius: 6px;
  padding: 12px 16px;
  text-align: center;
}
```

## 三、 审核弹窗 (Dialog — Audit)

### 1. 使用场景
在「待审核」Tab 点击「审核通过」或「审核驳回」时触发，弹出审核信息确认弹窗。

### 2. 视觉参数
* **宽度**：`width="540px"`，`align-center`
* **标题**：随操作动态变化（`审核通过确认` / `审核驳回确认`）
* **内容**：`el-descriptions` 展示申请信息 + 审核意见/驳回原因输入框（Textarea，可选）
* **底部按钮**：取消（默认）+ 确认按钮（通过时 `type="success"`，驳回时 `type="danger"`）

### 3. 实现要点

```javascript
// 同一弹窗，通过 action 参数区分通过/驳回模式
const auditAction = ref('approved') // 'approved' | 'rejected'

const openAudit = (row, action) => {
  currentAuditRow.value = row
  auditAction.value = action
  auditForm.value = { remark: '' }
  auditVisible.value = true
}
```

```html
<el-dialog
  v-model="auditVisible"
  :title="auditAction === 'approved' ? '审核通过确认' : '审核驳回确认'"
  width="540px"
  align-center
>
  ...
  <template #footer>
    <el-button @click="auditVisible = false">取消</el-button>
    <el-button
      :type="auditAction === 'approved' ? 'success' : 'danger'"
      @click="handleAudit"
    >{{ auditAction === 'approved' ? '确认通过' : '确认驳回' }}</el-button>
  </template>
</el-dialog>
```

## 四、 操作日志弹窗 (Dialog — Log)

### 1. 使用场景
点击「操作日志」按钮时，弹出该记录的完整操作历史。

### 2. 视觉参数
* **宽度**：`width="540px"`，`align-center`
* **内容**：`el-timeline`，时间轴按时间倒序排列，最新记录在最上方
* **底部按钮**：仅「关闭」（默认样式）

### 3. 时间轴节点样式
* 最新节点：`type="primary"`，实心节点
* 历史节点：`type="info"`，`hollow`（空心节点）
* 文案格式：`操作动作 · 操作人`

## 五、 通用规范

* **遮罩层**：点击遮罩默认**不关闭**弹窗（防止误触），须通过按钮关闭
* **弹窗层级**：Z-index 高于导航栏和内容区
* **国际化**：所有弹窗需在根节点配置 `<el-config-provider :locale="zhCn">` 以保证中文提示
