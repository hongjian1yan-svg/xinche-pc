> 所属系统：智慧车市  
> 所属模块：库容管理  
> 文档版本：v1.1  
> 状态：待评审

## 一、背景与目标

### 1.1 背景

平台金融系统在使用前需配置资金渠道信息（包含渠道名称、放款比例、车辆评估方式等）。现有方案中，资金渠道名称需要后端工程师直接操作数据库添加，每次新增渠道均依赖技术人员介入，效率低、维护成本高。

同时，系统现有"金融公司管理"功能仅维护金融公司基本信息，与资金渠道之间缺乏明确的层级关联，不能体现"一个金融公司下有多个资金产品"的真实业务结构。

### 1.2 目标

1. 在前端提供完整的资金渠道配置能力，消除对后端数据库操作的依赖
2. 建立"金融公司 → 资金渠道"的归属关系，使业务结构清晰可维护
3. 支持权限控制，超级管理员与市场管理员均可在授权范围内操作

### 1.3 不在本次范围内

- 临时出场默认限制：该配置项属于市场级全局设置，影响市场内所有金融冻结车，**保留在市场配置页面中，不纳入本次需求**
- 金融公司管理功能本身：现有功能基本不变，仅作为资金渠道的上级数据来源
- 旧版资金渠道数据迁移：现有三个开通金融业务的市场，由运营人员在新功能上线后手动完成重新配置；配置完毕并确认业务正常后，由研发从市场配置页面移除旧的资金渠道配置模块
- 金融订单编号前缀：属于市场配置页面的关联改动，详见第九章

## 二、信息架构

### 2.1 导航位置

在侧边栏"库容管理"菜单下新增子菜单项：

```
库容管理
├── 二次复核列表
├── 申请审核列表
├── 商户质押订单
├── 库融订单
├── 盘库列表
├── 临时出场列表
├── 金融公司管理
├── 资金渠道管理     ← 新增
└── 金融管控车管理
```

### 2.2 业务层级关系

```
市场（A市场）
└── 金融公司（如：泸州银行）
    └── 资金渠道（如：泸州银行-标准质押产品）
        ├── 渠道名称
        ├── 放款比例
        ├── 车辆评估选项
        └── 评估平台（自动评估时必填）
```

## 三、功能说明

### 3.1 页面：资金渠道管理列表

#### 3.1.1 页面布局

- 顶部：操作按钮区（新增渠道）
- 中部：筛选区（筛选条件 + 查询/重置按钮）
- 下部：数据表格 + 分页

#### 3.1.2 筛选条件

| 筛选项 | 组件类型 | 说明 |
|--------|----------|------|
| 市场名称 | 文本展示（只读） | 自动显示当前操作者所在市场，不可更改 |
| 金融公司 | 下拉选择 | 选项来源：当前市场下的金融公司列表；含"全部"默认项 |
| 渠道名称 | 文本输入 | 模糊搜索 |

操作按钮：**查询**（主要）、**重置**（次要）

#### 3.1.3 表格列定义

| 列名 | 说明 | 宽度建议 |
|------|------|----------|
| 所属市场 | 当前市场名称 | 固定 |
| 金融公司名称 | 所属金融公司 | 固定 |
| 渠道名称 | 资金渠道名称 | 固定 |
| 放款比例 | 数值 + % 单位 | 固定 |
| 车辆评估方式 | 自动评估 / 人工评估 | 固定 |
| 评估平台 | 多选平台名称，逗号分隔展示；人工评估时显示"—" | 自适应 |
| 创建时间 | yyyy-MM-dd HH:mm:ss | 固定 |
| 操作 | 见下方说明 | 固定 |

#### 3.1.4 操作列

| 操作 | 显示条件 | 权限要求 |
|------|----------|----------|
| 编辑 | 始终显示 | 需有编辑权限 |
| 删除 | 始终显示 | 需有删除权限；有引用时禁止删除 |
| 操作日志 | 始终显示 | 无权限限制 |

**删除保护规则：** 若该渠道已被金融订单引用（存在关联中的有效订单），点击删除时弹出提示：

> "该资金渠道已有关联订单，无法删除。如需停用，请联系管理员。"

#### 3.1.5 空状态

当前市场下无任何渠道数据时，表格区域显示空状态提示：

> "暂无资金渠道，点击「+ 新增渠道」开始配置"

### 3.2 新增 / 编辑渠道（抽屉）

使用右侧抽屉（Drawer）形式，与系统现有操作风格保持一致。

#### 3.2.1 抽屉标题

- 新增时：**新增资金渠道**
- 编辑时：**编辑资金渠道**

#### 3.2.2 表单字段

**① 渠道名称**

| 属性 | 说明 |
|------|------|
| 组件 | 单行文本输入框 |
| 必填 | 是 |
| 最大长度 | 50个字符 |
| 唯一性校验 | 同一市场下不允许重复；提交时后端校验，失败时在字段下方提示："该渠道名称已存在，请更换" |
| 编辑状态 | **再次编辑时不可修改**，字段置灰只读，仅新增时可填写 |

**② 所属金融公司**

| 属性 | 说明 |
|------|------|
| 组件 | 下拉选择（Select） |
| 必填 | 是 |
| 选项来源 | 当前市场下的金融公司列表（来自"金融公司管理"模块） |
| 编辑状态 | **再次编辑时不可修改**，字段置灰只读，仅新增时可选择 |
| 兜底处理 | 若当前市场无金融公司，下拉无选项，字段下方提示："当前市场暂无金融公司，请先前往「金融公司管理」完成配置" |

**③ 放款比例**

| 属性 | 说明 |
|------|------|
| 组件 | 数字输入框，后缀显示"%" |
| 必填 | 是 |
| 范围 | 1 ～ 100 的整数或最多保留两位小数 |
| 校验提示 | 超出范围时："放款比例须在 1% ～ 100% 之间" |
| 编辑状态 | **有进行中的关联订单时不可修改**，字段置灰只读；无进行中订单时可修改 |

**④ 车辆评估选项**

| 属性 | 说明 |
|------|------|
| 组件 | 单选按钮组（Radio Group） |
| 必填 | 是 |
| 选项 | 自动评估 / 人工评估 |
| 默认值 | 无默认，用户必须主动选择 |
| 联动规则 | 选择"自动评估"后，下方显示评估平台字段；选择"人工评估"后，评估平台字段隐藏 |
| 编辑状态 | 该资金渠道**存在进行中的关联订单时不可修改**（置灰只读，保留原选项及联动展示）；**无进行中关联订单时可修改** |

**⑤ 评估平台**（仅"自动评估"时显示）

| 属性 | 说明 |
|------|------|
| 组件 | 多选下拉（Multi-select） |
| 必填 | 是（自动评估时） |
| 选项来源 | 后端动态配置，前端通过接口获取 |
| 最少选择 | 1个 |
| 校验提示 | 未选择时："请至少选择一个评估平台" |

#### 3.2.3 抽屉底部操作

| 按钮 | 类型 | 行为 |
|------|------|------|
| 取消 | 次要按钮 | 关闭抽屉，不保存；若已有修改，弹出确认："当前修改尚未保存，确认离开？" |
| 保存 | 主要按钮 | 触发表单校验 → 提交 → 成功后关闭抽屉并刷新列表 |

## 四、交互规则与异常处理

### 4.1 表单校验时机

- 每个字段在失焦（onBlur）时触发单字段校验
- 点击"保存"时触发全字段校验
- 唯一性校验在提交时由后端返回

### 4.2 删除确认

点击"删除"时，弹出二次确认对话框：

> **确认删除该资金渠道？**  
> 渠道名称：[渠道名称]  
> 删除后不可恢复，请谨慎操作。  
>
> [取消]  [确认删除]

若后端返回"有关联订单"错误，关闭确认框，改为展示错误提示弹窗（见 3.1.4）。

### 4.3 评估平台接口异常

若评估平台选项接口请求失败，多选框显示为禁用状态，下方提示：

> "评估平台数据加载失败，请刷新页面重试"

### 4.4 网络/接口异常

所有增删改查操作若接口返回异常，统一在页面顶部以 Message 组件展示错误信息，不打断用户当前操作流程。

## 五、权限模型

| 角色 | 查看 | 新增 | 编辑 | 删除 |
|------|------|------|------|------|
| 超级管理员 | ✅ | ✅ | ✅ | ✅ |
| 市场管理员（已授权） | ✅ | ✅ | ✅ | ✅ |
| 市场管理员（未授权） | ✅ | ❌ | ❌ | ❌ |

**权限控制方式：**
- 无权限时，操作按钮（新增、编辑、删除）不展示或置灰，与系统现有权限处理方式保持一致
- 菜单入口的显隐由超级管理员在权限配置中控制

## 七、旧版数据处理说明

### 7.1 当前现状

市场配置页面（"编辑市场"）的金融系统设置中，现有"资金渠道"配置模块，支持输入渠道名称、放款比例、评估方式，以及"临时出场默认限制"。

目前共三个市场开通了金融业务，已存在部分旧渠道数据。

### 7.2 迁移方式

采用**人工重新配置**方式，不做自动化数据迁移：

1. 新功能上线后，由运营/管理员在"资金渠道管理"页面，为三个市场逐一配置渠道数据并关联正确的金融公司
2. 配置完成并确认金融业务运行正常后
3. 由研发将市场配置页面中的旧"资金渠道"配置模块移除

### 7.3 临时出场默认限制

该字段**不纳入本次迁移**，继续保留在市场配置页面中，作为市场级全局设置维护。

## 九、关联改动：市场配置 - 金融订单编号前缀

### 9.1 背景

金融订单编号由"前缀 + 日期 + 当日序号"组成，例如 `JHJR20260610001`。前缀用于标识订单所属市场，是对外可见的业务标识。

现有系统中该前缀由后端工程师手动维护，缺乏前端配置入口。随着资金渠道管理功能上线，需要一并提供前缀的配置能力，以完整支撑金融业务的自助开通流程。

### 9.2 改动位置

**市场配置页面 → 金融系统设置模块**，新增"金融订单编号前缀"配置项。

### 9.3 字段说明

| 属性 | 说明 |
|------|------|
| 字段名称 | 金融订单编号前缀 |
| 组件类型 | 单行文本输入框 |
| 必填条件 | 开启金融系统时必填 |
| 格式要求 | 2～6位大写字母，仅限字母（A-Z） |
| 唯一性 | 平台内所有市场的前缀不可重复 |
| 修改限制 | 该市场产生第一笔金融订单后，字段变为只读，不可修改；修改按钮置灰并 tooltip 提示："已有金融订单，编号前缀不可修改" |
| 权限 | 仅超级管理员可编辑（跟随市场配置现有权限，市场管理员无法访问市场配置页面） |

### 9.4 交互说明

**开启金融系统时的引导顺序：**

1. 超级管理员在市场配置中开启金融系统开关
2. 填写"金融订单编号前缀"（此时为必填，不填写无法保存）
3. 保存市场配置后，前往"金融公司管理"创建金融公司
4. 再前往"资金渠道管理"创建资金渠道
5. 金融系统正式可用

**唯一性校验：** 提交时后端校验，若前缀已被其他市场使用，在字段下方提示：

> "该编号前缀已被其他市场使用，请更换"

### 9.5 对验收标准的补充

| # | 验收项 | 通过条件 |
|---|--------|----------|
| 13 | 前缀配置入口 | 市场配置 → 金融系统设置中可见"金融订单编号前缀"字段 |
| 14 | 必填校验 | 开启金融系统时未填写前缀，保存时提示报错 |
| 15 | 格式校验 | 输入非大写字母或超出长度时提示格式错误 |
| 16 | 唯一性校验 | 填写已存在的前缀时提示报错，不保存 |
| 17 | 修改限制 | 已有订单后前缀字段变为只读，tooltip 提示正确 |
| 18 | 订单编号生成 | 新建金融订单后，编号前缀与市场配置中填写的前缀一致 |
