# 海西团购迭代升级 PRD

| 项目 | 内容 |
| --- | --- |
| 文档版本 | V1.7 |
| 日期 | 2026-09-03 |
| 状态 | PC 端团购与优惠券操作细则已补充 |
| 覆盖端 | 海西微信小程序、信车 PC 后台 |

## 1. 项目背景

海西小程序需支持用户先领取优惠券，再完成停车缴费、车况查询或购买线下核验团购产品。现有团购配置继续承担产品配置职责；优惠券规则从团购配置中拆分，由独立优惠券配置页维护。

## 2. 目标与范围

### 2.1 项目目标

- 建立停车缴费、车况查询、线下核验团购产品的统一领券与用券流程。
- 支持团购产品与优惠券独立配置、独立维护。
- 让用户在小程序中清晰了解优惠券适用品类、领取结果、实付价格与使用入口。

### 2.2 本期范围

| 端 | 本期内容 |
| --- | --- |
| 小程序 | 首页入口、会员福利、免费领券、停车缴费、车况查询、车况产品列表、团购详情、选券下单与领取成功页。 |
| PC 后台 | 复用既有团购配置作为产品配置载体；本期新增独立优惠券配置页。 |

### 2.3 不纳入范围

- 新建独立产品管理模块。
- 金额抵扣券、折扣券以外的优惠券类型。
- 车况产品维护方式调整；车况产品继续在车况初始化页面维护。
- 停车缴费业务能力改造；继续使用既有停车缴费业务。
- 团购列表外其他既有团购配置功能开发。
- 停车缴费记录相关页面开发。
- 车况查询“我的订单”页面开发。

## 3. 角色与术语

| 名称 | 定义 |
| --- | --- |
| 用户 | 使用海西小程序领取、使用优惠券及购买团购产品的用户。 |
| 团购产品 | 在团购配置中维护并展示给小程序用户的产品；可为原价产品或团购优惠产品。 |
| 优惠券 | 独立配置的金额抵扣券或折扣券，每张券仅绑定一个业务对象。 |
| 线下核验产品 | 用户线上下单支付后生成团购二维码，到店核销使用的团购产品。 |
| 原价 | 产品未应用团购优惠及优惠券时的价格。 |
| 实付价 | 先计算团购价，再计算优惠券后的用户支付金额。 |

## 4. 配置与数据规则

### 4.1 团购配置

- 团购配置仅维护产品、价格形态、购买方式与履约方式，不维护优惠券规则。
- 原价产品以普通商品形式在小程序展示，可使用关联且有效的优惠券。
- 团购优惠产品保留真实团购用途与团购优惠展示。
- 当团购商品以原价产品上架，且团购价与原价相等时，小程序列表仅展示红色价格，不展示删除线原价。
- 团购配置页面沿用既有产品、价格及履约能力；新增团购弹窗按本 PRD 第 6.2 节配置。

### 4.2 优惠券配置

- 每张优惠券仅绑定一个业务对象；同一业务对象可绑定多张优惠券。
- 支持金额抵扣券、折扣券；“免费领取”是领取方式，不是优惠券类型。
- 每张已领取优惠券仅可使用一次，使用后不可再次使用。
- 优惠券的所属市场、领取时间、使用有效期、总发放数量、每人领取次数、使用说明及是否可与团购优惠叠加均在 PC 端配置。
- 优惠券配置使用说明，限 500 字以内。
- 总发放数量和每人领取次数均支持“限制 / 不限制”；选择限制时配置具体数量或次数。
- 与团购优惠叠加默认关闭，可按优惠券单独开启。
- 「领取用户类型」「领取会员限制」与「用户类别」「会员限制」为两套独立配置、独立展示：前者约束谁可领取，后者约束谁可使用。

### 4.3 优惠券适用业务

| 适用业务 | 绑定对象 | 小程序使用方式 |
| --- | --- | --- |
| 原价商品 / 团购优惠商品 | 团购配置中对应类型的一个已上架产品 | 线上下单；线下核验产品支付成功后生成团购二维码。 |
| 车况查询 | 车况初始化中已维护的车况产品或套餐 | 领取后进入车况产品列表或产品录入页。 |
| 停车缴费 | 不绑定具体产品；列表与详情「绑定对象」展示「—」 | 输入车牌、选择可用停车券、在线缴费后道闸抬杆。 |

- 停车缴费券适用于所选市场内全部线上停车缴费订单，不绑定团购或具体停车产品。

## 5. 价格与选券规则

### 5.1 价格计算

- 原价产品可使用所绑定且当前可用的优惠券。
- 团购优惠产品默认不可再使用优惠券；仅当优惠券明确开启“可与团购优惠叠加”时，允许双重优惠。
- 计算顺序为：原价 → 团购价 → 优惠券抵扣或折扣 → 实付价。
- 实付价不得小于 0 元。

### 5.2 订单选券

- 停车缴费订单页、车况查询订单页及线下团购产品订单页均使用本节选券规则。
- 提交订单页的优惠券模块仅展示当前业务和绑定对象下可用的已领取优惠券；无可用券时展示“无可用优惠券”。
- 点击优惠券模块进入弹窗后，仅展示适用于当前业务和绑定对象的未使用优惠券；已使用优惠券不在弹窗中展示。满足业务和绑定对象、但不满足其他使用条件的优惠券置灰展示。
- 多张可用券时，默认选中按当前商品计算后实付金额最低的一张。
- 用户可点击已选优惠券，切换其他可用券或取消使用优惠券。
- 点击置灰优惠券时，按以下优先级 Toast 提示不可用原因：
  1. 该优惠券已下架；
  2. 该优惠券不在使用有效期内；
  3. 当前用户类型不满足使用条件；
  4. 当前会员身份不满足使用条件；
  5. 当前注册时间不满足使用条件；
  6. 当前注册时长不满足使用条件；
  7. 当前认证时间不满足使用条件；
  8. 您优惠券使用次数已达上限；
  9. 您今日优惠券使用次数已达上限；
  10. 您本月优惠券使用次数已达上限；
  11. 该优惠券不可与当前团购优惠叠加使用（仅团购价商品）。
- 停车券领取限制、总发放数量及每人领取次数只影响领券，不作为订单页的优惠券不可用原因。

### 5.3 团购详情价格展示

- 团购详情页红色主价格展示优惠券抵扣后的实付价。
- 原价在主价格下方以小字、删除线形式展示。
- 实付价为 0 元时，红色主价格展示“免费”，不展示“￥0.00”；原价仍保留展示。

## 6. PC 端产品规划

### 6.1 菜单与信息架构

- 在“C端会员管理”下新增二级菜单“团购优惠券管理”。
- “团购优惠券管理”包含“团购商品”“优惠券配置”两个 Tab。
- 原“卡券管理”中的“团购卡券”迁入“团购商品”；原“卡券管理”保留非团购类卡券能力。
- 所属市场正式名称使用「厦门海西名车MALL」。

### 6.2 团购商品

#### 6.2.1 列表、筛选与导出

- 团购商品复用原“卡券管理 > 团购卡券”的既有商品配置、上下架及履约能力；继续维护产品、价格形态、购买方式与履约方式，不配置优惠券领取、有效期、限领或叠加规则。
- 列表上方提供状态 Tab：待上架、上架中、已下架。
- 筛选字段：所属市场、团购名称、团购类型、创建时间、预计上架时间。操作按钮：新增团购、查询、重置、查询数据导出。
- 「查询数据导出」导出当前列表全部列内容。
- 团购商品列表固定展示：所属市场、团购类型、团购名称、商品原价、商品团购价、核验服务商、数量限制、团购数量、上架类型、有效期、购买限制、核销限制、会员限制、支持退款、下架时间、创建时间、上架时间、上架人及操作。
- 不展示「车况套餐」「满减限制」。
- 「核验服务商」展示已选服务商；未配置时展示「—」。
- 「下架时间」展示计划下架日期；选择永不下架时展示「永不下架」。
- 已确认列表字段未经需求确认不得隐藏或删除。

#### 6.2.2 新增团购

- 弹窗标题为「新增团购」，分两步；团购类型说明文案为「两类商品均为线下核销商品」。
- 第一步「团购基本信息」字段：

| 字段 | 规则 |
| --- | --- |
| 所属市场 | 必填；可选「厦门海西名车MALL」。 |
| 团购类型 | 必填；可选「原价商品」「团购优惠商品」；两类均为线下核销商品。 |
| 团购名称 | 必填。 |
| 商品图片 | 非必填；支持 png、jpg、jpeg；尺寸 750×480px；最多 10 张。 |
| 商品原价 | 必填；单位元。 |
| 商品团购价 | 仅「团购优惠商品」展示；「原价商品」不展示该字段。开关默认关闭；开启后展示金额输入且必填，关闭后隐藏金额输入。 |
| 核验服务商 | 开关默认开启且开启时必填；开启后可按名称搜索并多选服务商；关闭后隐藏选择框且不校验。 |
| 数量限制 | 必填；有限 / 不限；选有限时展示数量输入框（张）。 |
| 上架类型 | 必填；到期自动上架 / 立即上架。 |
| 计划下架时间 | 必填；可勾选「永不下架」。 |

- 新增团购弹窗不配置「满减限制」。
- 选择「原价商品」时仅配置第一步，不展示「商品团购价」，底部主按钮为「确定」。
- 选择「团购优惠商品」时展示「商品团购价」，并进入第二步「团购核销设置」，字段包括：可用项目（限制 16 字以内）、有效期、用户类别、会员限制、用户限制、购买限制、核销限制、使用说明（500 字以内）。
- 第二步「用户限制」选项及附加项与优惠券配置相同：不限无附加项；按注册时间展示必填「注册时间」日期区间；按注册时长展示必填「注册满」数字 + 单位「天」；按认证时间展示必填「认证日期」日期区间。

#### 6.2.3 详情与操作

- 操作列展示「查看」和「更多操作」。
  - 「待上架」「上架中」：更多操作包含「编辑信息」「提前下架」「操作日志」。
  - 「已下架」：更多操作仅包含「删除」，不可再上架。
- 点击「查看」后以右侧详情抽屉展示：第一步字段归入「卡券信息」，第二步字段归入「分配核销」；「核验服务商」在详情中展示，未配置时为「—」；不展示「车况套餐」「满减限制」。

##### 编辑信息

- 按钮文案为「编辑信息」（不以「编辑卡券」命名）。
- 点击后弹出团购编辑弹窗；弹窗内容结构、步骤与样式与「新增团购」弹窗保持一致。
- 弹窗内字段均按当前团购数据回填展示；仅下列字段可编辑，其余字段只读不可改：

| 步骤 | 可编辑字段 |
| --- | --- |
| 第一步「团购基本信息」 | 团购名称、商品图片、核验服务商、数量限制、计划下架时间（含永不下架） |
| 第二步「团购核销设置」 | 使用说明 |

- 「原价商品」仅有第一步，按上表第一步可编辑范围处理；「团购优惠商品」进入第二步时仅「使用说明」可编辑。
- 保存后关闭弹窗并刷新列表展示。

##### 提前下架

- 点击「提前下架」后弹出二次确认弹窗。
- 确认弹窗采用 PC 端设计规范中的**简洁款**：标题「提示」；宽 380px；居中；不可点击遮罩关闭；内容为左侧警告图标（WarningFilled，色值 `#E6A23C`，18–22px）+ 右侧提示文案「确认提前下架该团购？」；底部按钮为「取消」+「确定」（主按钮蓝色填充）。
- 点击「确定」后该团购下架，状态变为「已下架」，信息出现在「已下架」Tab；点击「取消」关闭弹窗，不变更状态。
- 团购下架后，不影响用户已购买但未核销的团购订单。

##### 删除

- 仅「已下架」Tab 的更多操作展示「删除」。
- 点击「删除」后弹出二次确认弹窗，样式与「提前下架」确认弹窗保持一致；提示文案为「确认删除该团购？」。
- 点击「确定」后删除该条团购信息并刷新列表；点击「取消」关闭弹窗，不删除。
- 已下架团购不可再上架。

##### 操作日志

- 点击「操作日志」后弹出操作日志弹窗。
- 弹窗样式：标题「操作日志」；右上角关闭；中间为表格；底部右侧「取消」「确定」（主按钮蓝色填充）。
- 表格字段固定为：操作人、操作介绍、操作时间；表头与单元格内容居中；单元格带边框。
- 展示示例：操作人「曲伟」、操作介绍「立即上架」、操作时间「2026-06-25 13:44:02」。

### 6.3 优惠券配置

#### 6.3.1 列表、筛选与导出

- 优惠券配置与团购商品并列，独立维护；不承载团购商品上下架、履约或核销能力。
- 筛选字段：所属市场、优惠券名称、优惠券类型、状态、适用业务、绑定对象、创建时间。操作按钮：新增优惠券、查询、重置、查询数据导出。
- 「查询数据导出」导出当前列表全部列内容。
- 优惠券列表固定展示：所属市场、优惠券名称、优惠类型、优惠数值、适用业务、绑定对象、与团购优惠叠加、发放总量、每人领取次数、领取用户类型、领取会员限制、有效期、用户类别、会员限制、领取限制、用户限制、创建时间、状态及操作。
- 列表与详情均不展示「购买限制」「核销限制」。
- 「与团购优惠叠加」仅团购优惠商品券展示不叠加或叠加，其他业务显示「—」。
- 「领取限制」仅停车缴费券展示配置值，其他业务显示「—」。
- 停车缴费券「绑定对象」显示「—」。
- 「领取用户类型」「领取会员限制」与「用户类别」「会员限制」分列独立展示。
- 已确认列表字段未经需求确认不得隐藏或删除。

#### 6.3.2 新增优惠券

- 弹窗标题为「新增优惠券」，分两步。
- 第一步「优惠券基本信息」字段：

| 字段 | 规则 |
| --- | --- |
| 所属市场 | 必填；可选「厦门海西名车MALL」。 |
| 优惠券名称 | 必填。 |
| 适用业务 | 必填；可选原价商品、团购优惠商品、车况查询、停车缴费。 |
| 绑定对象 | 停车缴费不展示；原价商品、团购优惠商品、车况查询必填。选择原价商品或团购优惠商品时，仅展示对应类型的已上架团购商品。 |
| 优惠类型 | 必填；抵扣 / 折扣。抵扣输入金额（元）；折扣输入数值（如 8.8），后缀为「折扣」。 |
| 领取时间 | 必填；不限制 / 限制；选限制时选择日期区间。 |
| 使用有效期 | 必填；不限制 / 限制；选限制时选择日期区间。 |
| 总发放数量 | 必填；不限制 / 限制；选限制时输入张数。 |
| 每人领取次数 | 必填；不限制 / 限制；选限制时输入次数。 |
| 领取用户类型 | 必填；不限 / 车商用户 / 非车商用户。 |
| 领取会员限制 | 必填；不限 / 认证会员 / 普通会员。 |
| 与团购优惠叠加 | 仅当适用业务为团购优惠商品且已绑定商品时展示；可选不叠加、叠加，默认不叠加；其他适用业务不展示。 |

- 优惠类型为「抵扣」且绑定团购商品时：抵扣金额不得大于商品价格；上限优先取商品团购价，未配置团购价时取商品原价。
- 优惠类型为「折扣」时：折扣数值需大于 0 且小于 10。
- 第二步「使用资格限制」字段：

| 字段 | 规则 |
| --- | --- |
| 用户类别 | 必填；不限 / 车商用户 / 非车商用户；与第一步「领取用户类型」独立配置。 |
| 会员限制 | 必填；不限 / 认证会员 / 普通会员；与第一步「领取会员限制」独立配置。 |
| 停车券领取限制 | 仅适用业务为停车缴费时展示；开 / 关。开启时：用户已领取停车券但未使用情况下，无法再次领取停车券。 |
| 用户限制 | 必填；不限 / 按注册时间 / 按注册时长 / 按认证时间。选中后按下列规则展示附加项。 |
| 使用限制 | 必填；不限 / 日限 / 月限 / 一次。日限或月限时配置限制次数；选择一次时仅允许使用一次。 |
| 使用说明 | 非必填；限 500 字以内。 |

- 「用户限制」附加项（选「不限」时不展示附加项）：

| 用户限制选项 | 附加字段 | 规则 |
| --- | --- | --- |
| 按注册时间 | 注册时间 | 必填；日期区间，占位「开始日期 - 结束日期」。 |
| 按注册时长 | 注册满 | 必填；数字输入，占位「请输入数字」；右侧单位下拉，默认「天」。 |
| 按认证时间 | 认证日期 | 必填；日期区间，占位「开始日期 - 结束日期」。 |

- 「使用限制」按同一用户生效；优惠券使用次数以优惠券成功抵扣订单为准，不限制线下核销；线下核销仅受团购商品的核销限制控制。
- 使用优惠券的团购订单发生退款、未支付取消或支付失败时，均退回该优惠券，并回退对应的优惠券使用次数。

#### 6.3.3 详情与操作

- 操作列展示「查看」和「更多操作」；更多操作包含「编辑」「下架 / 上架」（随状态切换）、「删除」「操作日志」。
- 点击「查看」后以右侧详情抽屉展示当前列表中的优惠券信息，分区为「优惠券信息」与「使用资格限制」；字段与列表一致，不含「购买限制」「核销限制」；停车缴费「绑定对象」为「—」。
- 状态「已上架」以绿色标签展示；状态「已下架」以红色标签展示。

##### 编辑

- 点击「编辑」后弹出优惠券编辑弹窗；弹窗内容结构、步骤与样式与「新增优惠券」弹窗保持一致。
- 弹窗内字段均按当前优惠券数据回填展示；仅下列字段可编辑，其余字段只读不可改：

| 步骤 | 可编辑字段 |
| --- | --- |
| 第一步「优惠券基本信息」 | 优惠券名称、总发放数量 |
| 第二步「使用资格限制」 | 使用说明 |

- 保存后关闭弹窗并刷新列表展示。

##### 下架 / 上架

- 优惠券为「已上架」时，更多操作展示「下架」；为「已下架」时，该入口改为「上架」。
- 点击「下架」或「上架」后均弹出二次确认弹窗，样式与团购「提前下架」确认弹窗保持一致（简洁款：标题「提示」、宽 380px、警告图标 + 文案、取消 / 确定）。
- 「下架」提示文案为「确认下架该优惠券？」；点击「确定」后状态变为「已下架」，列表以红色标签展示。
- 「上架」提示文案为「确认上架该优惠券？」；点击「确定」后状态变为「已上架」，列表以绿色标签展示。
- 点击「取消」关闭弹窗，不变更状态。
- 优惠券下架后，不影响用户已领取但未使用的优惠券。

##### 删除

- 点击「删除」后弹出二次确认弹窗，样式与下架确认弹窗保持一致。
- 提示文案为「确认删除该优惠券？」。
- 点击「确定」后删除该条优惠券信息，并刷新列表；点击「取消」关闭弹窗，不删除。

##### 操作日志

- 点击「操作日志」后弹出操作日志弹窗。
- 字段与样式与团购操作日志保持一致：操作人、操作介绍、操作时间；弹窗含标题、关闭、表格及底部「取消」「确定」。

### 6.4 迁移与数据保持

- 原团购卡券的团购 ID、上架状态、历史订单、退款审核及核销记录保持不变。
- 菜单迁移后，原入口不再承载团购卡券配置；已存在的团购商品应可从新入口继续查询和维护。
- 本期不修改停车缴费记录、车况「我的订单」等既有页面。

## 7. 小程序页面与功能需求

### 7.1 首页

首页提供以下入口：会员福利、停车缴费、车况查询。

| 入口 | 展示内容 | 主流程 |
| --- | --- | --- |
| 会员福利 | 免费领券、超值团购两个 Tab | 领券或进入团购详情购买。 |
| 停车缴费 | 停车缴费优惠券 | 领取停车券 → 停车缴费。 |
| 车况查询 | 车况查询优惠券 | 领取车况券 → 查询车况。 |

### 7.2 会员福利

#### 免费领券

- 展示停车缴费券、车况查询券及汽车洗美、汽车空调清洗等线下核验产品优惠券。
- 优惠券名称需体现具体优惠金额或免费权益，例如“10元停车优惠券”“汽车空调清洗免费券”。
- 所有优惠券卡片操作按钮统一展示“免费领取”。领取后返回列表，按钮不改为使用入口。
- 再次点击“免费领取”时，按配置校验领取限制：总发放数量达到上限提示“该优惠券已领完”；当前用户达到领取次数上限提示“您已达到该优惠券的领取上限”。

#### 超值团购

- 展示由团购配置承载的原价产品与真实团购优惠产品。
- 列表中仅展示红色价格，不展示删除线原价。

#### 领取成功页

- 展示领取成功状态、优惠券信息、使用规则与订单信息。
- 订单信息字段包括手机号、领取时间。
- 底部主按钮随优惠券业务类型变化：

| 优惠券类型 | 底部按钮 | 点击结果 |
| --- | --- | --- |
| 停车缴费券 | 立即缴费 | 进入停车缴费页。 |
| 车况查询券 | 查询车况 | 进入车况产品列表页。 |
| 线下核验产品券 | 立即使用 | 进入该优惠券绑定产品的团购详情页。 |

- 线下核验产品券即使配置“每人领取次数限制 1 次”，领取成功页仍展示“立即使用”；领取限制仅影响再次领取校验。

### 7.3 停车缴费

- 停车缴费优惠券卡片展示“免费领取”，领取成功页通过“立即缴费”进入停车缴费页。
- 停车缴费页展示停车券使用提示、车牌号输入区、“查询缴费”按钮和“缴费记录”入口；缴费记录相关页面复用既有页面，不在本期开发。
- 停车券仅可在小程序领取及使用；用户应在出场前完成缴费。
- 用户输入车牌后，系统默认选择当前可用停车券，再进入在线缴费及道闸抬杆流程。

### 7.4 车况查询

- 车况查询优惠券卡片统一展示“免费领取”；点击后进入领取成功页。
- 领取成功页的底部按钮展示“查询车况”，点击进入车况产品列表页。
- 车况产品列表包含“车况套餐”“我的订单”两个 Tab；“我的订单”复用既有页面，不在本期开发。
- 可使用优惠券的车况产品展示“可使用优惠券”标签，点击进入对应产品录入页。

### 7.5 线下核验团购产品

- 流程为：领取优惠券 → 点击“立即使用” → 进入绑定产品团购详情 → 默认选券 → 下单支付 → 生成团购二维码 → 到店核销。
- 团购详情的产品名称、产品品类、可用项目必须与已领取优惠券的绑定产品一致。
- 新增汽车空调清洗免费券，绑定汽车空调清洗团购产品；该券可使产品实付价为 0 元，并按第 5.3 节展示“免费”。
- 团购详情页展示产品图片、产品名称、产品品类、优惠后实付价、原价、退款说明、有效期、可用项目与购买按钮。
- 有效期由 PC 端优惠券配置提供。
- 优惠券使用说明在 PC 端配置（见第 6.3 节）。

## 8. 页面返回规则

- 从车况产品列表返回，回到车况查询优惠券页；从车况产品录入页返回，回到车况产品列表页。
- 从停车缴费页返回，回到停车缴费优惠券页；从缴费完成页返回，回到停车缴费页。
- 从领取成功页返回，回到发起领取的页面。

## 9. 异常与边界

| 场景 | 处理方式 |
| --- | --- |
| 优惠券总发放数量已达上限 | 提示“该优惠券已领完”。 |
| 当前用户已达领取次数上限 | 提示“您已达到该优惠券的领取上限”。 |
| 当前业务无可用优惠券 | 展示空视图文案“暂无可用优惠券”。 |
| 优惠券抵扣金额高于订单金额 | 实付价按 0 元计算，并展示“免费”。 |
| 领取后返回列表 | 列表按钮继续显示“免费领取”，再次点击时执行领取限制校验。 |

## 10. 验收标准

- 小程序首页可进入会员福利、停车缴费、车况查询三个入口。
- 各业务优惠券仅展示本业务可领取的券；无券时展示“暂无可用优惠券”。
- 免费领取、领取限制提示、领取成功页底部动作符合第 7.2 节。
- 停车缴费、车况查询及线下核验产品的页面返回关系符合第 8 节。
- 团购详情价格、原价及 0 元“免费”展示符合第 5.3 节。
- 线下核验券点击“立即使用”后，进入与该券绑定且品类一致的团购详情。
- PC 菜单名为「团购优惠券管理」；团购商品与优惠券配置的列表字段、筛选、导出、表单显隐与校验符合第 6 节。
- 团购列表/详情含「核验服务商」（未配置为「—」），不含「车况套餐」「满减限制」。
- 优惠券列表/详情不含「购买限制」「核销限制」；停车缴费「绑定对象」为「—」；领取侧与使用侧用户/会员限制独立展示。
- PC 团购操作：「编辑信息」可编辑范围、「提前下架」流转至已下架且不影响已购未核销、「已下架」仅可删除不可再上架、「操作日志」弹窗符合第 6.2.3 节。
- PC 优惠券操作：「编辑」可编辑范围、「下架 / 上架」按状态切换并二次确认且下架不影响已领未用、「删除」确认后移除、「操作日志」与团购一致，符合第 6.3.3 节。
- 「用户限制」按注册时间 / 注册时长 / 认证时间的附加字段符合第 6.2.2、6.3.2 节。
