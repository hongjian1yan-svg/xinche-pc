## PC 已实现范围（预览）

### 团购商品

- 菜单名：团购优惠券管理；所属市场正式名：厦门海西名车MALL。
- 团购类型：原价商品、团购优惠商品；两类均为线下核销商品。
- 原价商品只配置第一步「团购基本信息」；团购优惠商品继续配置第二步「团购核销设置」。
- 第一步含商品原价、可选商品团购价（仅团购优惠商品）、核验服务商、数量限制、上架与下架时间等；原价商品不展示商品团购价；列表、详情与新增弹窗均不展示满减限制。
- 核验服务商默认开启且必填，支持名称搜索与多选；关闭时隐藏选择区域且不校验；列表与详情需展示，未配置为「—」。
- 数量限制选「有限」后展示张输入框。
- 列表与详情不展示「车况套餐」。
- 商品详情采用右侧抽屉：第一步字段归入「卡券信息」，第二步归入「分配核销」。
- 「查询数据导出」导出列表全部列内容。
- 操作：待上架/上架中含「编辑信息 / 提前下架 / 操作日志」；已下架仅「删除」不可再上架；下架不影响已购未核销。

### 优惠券配置

- 适用业务：原价商品、团购优惠商品、车况查询、停车缴费；新增表单必填「所属市场」。
- 团购优惠商品绑定后显示「与团购优惠叠加」，默认不叠加；其他业务不显示该项。
- 仅停车缴费展示「停车券领取限制」；停车缴费「绑定对象」列表/详情显示「—」。
- 优惠类型为抵扣时：已配置团购价的商品校验团购价；仅配置原价的商品校验原价。
- 保留「使用说明」（500 字以内）；列表/详情不含「购买限制」「核销限制」。
- 「领取用户类型 / 领取会员限制」与「用户类别 / 会员限制」两套独立配置、独立展示。
- 筛选字段：优惠券名称、优惠券类型（及所属市场、状态、适用业务、绑定对象、创建时间）。
- 操作：「编辑 / 下架·上架 / 删除 / 操作日志」；下架不影响已领未用。
- 用户限制含注册时间 / 注册满 / 认证日期附加项。

### 列表约束

- 团购列表和优惠券列表字段以 PRD 第 6 节为准；未收到明确需求时，不得隐藏、删除或调整既有字段。
- 两张列表列宽已收窄，超宽内容在表格区域横向查看。

## 小程序范围摘要（对齐 PRD V1.8 / Figma）

- 首页：「会员福利」与「超值团购」拆为两个独立入口，另含停车缴费、车况查询。
- 会员福利：展示 PC 配置的全部优惠券；卡片含名称、绑定对象、有效期（无则不展示）；领取置灰、「去使用」；入口「查看优惠券/团购」。
- 超值团购：展示全部团购商品；列表分三种价格（券后价、原价、团购价+原价）。
- 团购详情：已领券展示券后价；无券有团购价展示团购价；否则展示原价；券后 0 元展示「免费」且按钮为「立即下单」。
- 车况查询：顶部优先展示车况券；无可用券展示「无可用优惠券」。
- 个人中心：「我的优惠」改为「优惠券/团购」；状态含待使用 / 已失效 / 已使用；按钮按业务为查询车况 / 停车缴费 / 去用券。
- 非认证用户用券拦截弹窗，引导认证；认证后默认选券。细则与待确认见 PRD 第 7、11 节。

## 编辑约定

- 仅维护原生 HTML、CSS、JavaScript，不创建 Vue、React、Vite 等工程或依赖文件。
- PC 预览为自包含单文件；模拟数据，真实接口与持久化不在当前范围。
- 修改业务字段、规则或交互时，同时更新 PRD；不要基于推测增加字段、选项、校验或文案。
- 小程序以 Figma + PRD 为准；改 PRD 小程序章节时须对照设计稿旁注，缺口写入「待确认事项」。
- 修改 PC 预览后需实际打开页面，验证关键状态、相邻布局和脚本无报错。
