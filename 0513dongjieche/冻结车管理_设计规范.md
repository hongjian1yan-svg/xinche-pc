## 四、组件使用规范

### 4.1 按钮（el-button）

| 场景 | type | size | 说明 |
|------|------|------|------|
| 主要操作（查询、解冻、确认）| `primary` | `large` | 列表页筛选区主按钮 |
| 次要操作（重置）| — | `large` | 与主按钮同 size 对齐 |
| 工具按钮（日志、审核）| — / `primary` / `warning` / `danger` | `small` | 表格行内操作 |
| 设置页添加按钮 | `primary` | 默认 | 冻结车设置页添加按钮 |

> 同一工具栏内的按钮必须保持 size 一致。

### 4.2 表格（el-table）

```
:header-cell-style="{ background: '#F5F7FA', color: '#909399', fontWeight: 'bold', textAlign: 'center' }"
border
```

- 所有表格必须带 `border` 属性
- 行高固定为 **54px**（`:deep(.el-table__row) { height: 54px }`）
- 操作列固定在右侧（`fixed="right"`），宽度 150px
- 操作列按钮之间 margin 重置为 0（避免 Element Plus 默认间距叠加）

### 4.3 弹窗（el-dialog）

| 弹窗类型 | 宽度 |
|---------|------|
| 操作日志 | 600px |
| 冻结/解冻确认（手动来源） | 520px |
| 解冻/审核（标准） | 420px–480px |
| 添加解冻原因 | 550px |
| 车辆详情 | 800px（全屏抽屉式）|

- 所有弹窗使用 `align-center` 居中显示
- 弹窗内表单 `label-width: 80–100px`

### 4.4 表单（el-form）

- 筛选区表单使用 `inline` 模式
- 筛选输入框统一宽度：`200px`
- 筛选输入框统一高度：`40px`（`size="large"`）
- 表单标签宽度：`80px`（列表筛选区）

### 4.5 选项卡（el-tabs）

- 冻结车设置页使用 Element Plus 默认 tabs 样式（含底部高亮下划线）
- 冻结车列表页使用**自定义 Tab**（`.tab-item`）而非 el-tabs，样式：
  - 未激活：背景 `#f9fafb`，边框 `#e3e4e5 + border-bottom:none`，尺寸 90×40px
  - 激活：背景 `#f2f2f2`
  - Hover：背景 `#ecf5ff`，文字 `#409eff`

### 4.6 描述列表（el-descriptions）

- 详情弹窗内的信息展示统一使用 `el-descriptions`，`border` 属性开启
- 每组两列（`:column="2"`）

### 4.7 标签/气泡

```css
/* 通用状态标签 */
min-width: 68px;  height: 20px;  padding: 0 8px;
border-radius: 4px;  font-size: 12px;

/* 冻结状态标签 */
background: #fef0f0;  border: 1px solid #fbc4c4;
color: #F56C6C;  font-weight: 500;

/* 普通状态标签 */
background: #d0e2f2;  color: #1d2c4f;

/* 车牌号标签 */
background: #f4f4f5;  border: 1px solid #e9e9eb;
color: #303133;  font-family: monospace;  font-size: 13px;
padding: 2px 8px;  border-radius: 3px;
```

## 五、布局规范

### 5.1 整体结构

```
┌──────────────────────────────────────────────────────┐
│  顶部 Logo 栏（height: 90px, padding: 0 20px）         │
├──────────┬───────────────────────────────────────────┤
│          │  Tab 栏（自定义，height: 40px tab-item）   │
│  侧边栏  ├───────────────────────────────────────────┤
│（Menu）  │  筛选区（search-filter-container）         │
│          ├───────────────────────────────────────────┤
│          │  表格区（view-container / el-table）       │
└──────────┴───────────────────────────────────────────┘
```

### 5.2 侧边栏菜单

- 使用 `el-menu` 组件，`router` 模式关闭（纯 JS 路由切换）
- 激活项：背景 `#48528e`，文字 `#ffffff`
- Hover：背景 `#f2f7ff`，文字 `#409eff`
- 右边框取消（`border-right: none`）

### 5.3 详情区段标题

```css
border-left: 4px solid #48528e;
padding-left: 10px;
font-size: 14px;
font-weight: bold;
color: #303133;
```
