# 冻结车列表 · 二期需求文档（PRD）

**模块路径：** 车辆管理 → 冻结车列表  
**文档版本：** v1.0  
**文档状态：** 待评审  

---

## 一、背景与目标

### 1.1 背景

一期冻结车列表仅收录「手动冻结」来源的车辆，由管理员在车辆列表中手动操作冻结，车商可在信车 APP 发起解冻申请，管理员在 PC 端审核。

二期目标是**丰富冻结来源**，将系统中所有冻结车集中至本模块统一管理，同时在列表和筛选中展示冻结来源标识。

### 1.2 目标

- 新增 3 种冻结来源：金融质押冻结、合同到期冻结、金融管控冻结
- 在列表新增「冻结来源」标签列
- 新增「冻结来源」筛选条件
- 根据不同来源区分解冻权限与操作入口
- Tab 状态根据冻结来源筛选动态联动显示

---

## 二、菜单访问权限

本模块涉及的两个功能页面均需通过系统角色权限配置才可访问，默认开放角色如下：

| 功能页面 | 默认可访问角色 | 说明 |
|--------|------------|-----|
| 冻结车列表 | 超级管理员、市场管理员、金融管控管理员 | 其他角色默认不可见，可通过角色配置手动开放 |
| 冻结车设置 | 超级管理员、市场管理员、金融管控管理员 | 其他角色默认不可见，可通过角色配置手动开放 |

## 三、冻结来源说明

| 冻结来源 | 触发方式 | 解冻方式 | 可操作解冻角色 | 是否需要审核 | 可在本页解冻 |
|--------|--------|--------|------------|----------|----------|
| 手动冻结 | 管理员在车辆列表手动操作 | 管理员手动解冻（需审核） | 市场管理员、超级管理员 | ✅ 需要 | ✅ |
| 金融质押冻结 | 车辆质押后系统自动冻结 | 还款完成后系统自动解冻 | 系统自动，无需人工干预 | — | ❌ 仅展示 |
| 合同到期冻结 | 摊位合同到期后系统自动冻结 | 管理员手动解冻 | 市场管理员、超级管理员 | ❌ 无需审核 | ✅ |
| 金融管控冻结 | 金融管控管理员手动添加 | 金融管控管理员手动解冻 | 金融管控管理员、超级管理员 | ❌ 无需审核 | ✅ |

### 4.5 解冻交互流程

#### 手动冻结 — 解冻流程（需审核）

```
车商在信车 APP 申请解冻
    → 选择解冻原因（来自冻结车设置中配置的原因）
    → 进入「待审核」Tab
    → 市场管理员 / 超级管理员在 PC 端审核
        → 审核通过：车辆解冻，进入「审核通过」Tab
        → 审核驳回：车辆维持冻结，进入「审核驳回」Tab
```

#### 合同到期冻结 — 解冻流程（无需审核）

```
市场管理员 / 超级管理员在冻结车列表操作解冻
    → 直接解冻，进入「已解冻」Tab
```

#### 金融管控冻结 — 解冻流程（无需审核）

```
金融管控管理员 / 超级管理员在冻结车列表操作解冻
    → 直接解冻，进入「已解冻」Tab
```

#### 金融质押冻结 — 解冻流程（系统自动）

```
系统检测到还款完成
    → 自动解冻，进入「已解冻」Tab
    → 无人工干预入口
```

## 六、冻结车设置

**模块路径：** 车辆管理 → 冻结车设置  
**功能定位：** 分别配置「冻结原因」和「解冻原因」选项，仅适用于手动冻结车辆。  
**访问权限：** 超级管理员、市场管理员、金融管控管理员。

页面通过 Tab 切换「冻结原因」与「解冻原因」两个配置区，结构对称，各自独立管理。

---

### 6.1 冻结原因配置

**功能定位：** 管理员在车辆列表手动冻结车辆时，从本处配置的原因列表中选择冻结原因；选定的原因会在冻结车列表详情页和车辆详情页中展示。

#### 筛选区域

| 筛选项 | 类型 | 说明 |
|------|------|------|
| 市场名称 | 文本输入 | 按市场名称模糊搜索 |
| 创建时间 | 日期范围 | 按配置创建时间筛选 |

#### 配置列表字段

| 字段 | 说明 |
|-----|-----|
| 市场名称 | 该冻结原因所属市场 |
| 冻结原因 | 原因文案，管理员冻结车辆时选择 |
| 创建时间 | 配置创建时间 |
| 操作 | 编辑 / 删除 |

#### 添加 / 编辑冻结原因

点击右上角「添加冻结原因」或列表操作列「编辑」，弹出对话框。

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| 市场名称 | 下拉选择（必填） | 选择所属市场；编辑时不可修改 |
| 冻结原因 | 文本输入（必填） | 自定义原因文案 |

#### 删除确认

点击列表操作列「删除」后，弹出二次确认弹窗，确认后方可删除，防止误操作。

#### 关联说明

- 本处配置的冻结原因列表影响管理员在车辆列表手动冻结时的可选原因
- 不同市场的冻结原因相互独立
- 删除后，历史已关联该原因的冻结记录不受影响

---

### 6.2 解冻原因配置

**功能定位：** 配置解冻原因选项及对应有效期，供车商在信车 APP 申请解冻时选择。  
**适用范围：** 仅限手动冻结车辆。

#### 筛选区域

| 筛选项 | 类型 | 说明 |
|------|------|------|
| 市场名称 | 文本输入 | 按市场名称模糊搜索 |
| 创建时间 | 日期范围 | 按配置创建时间筛选 |

#### 配置列表字段

| 字段 | 说明 |
|-----|-----|
| 市场名称 | 该解冻原因所属市场 |
| 解冻原因 | 原因文案，车商在 APP 选择时展示 |
| 解冻有效期 | 无限制 / X天 / X天X小时 |
| 创建时间 | 配置创建时间 |
| 操作 | 编辑 / 删除 |

#### 添加 / 编辑解冻原因

点击页面右上角「添加解冻原因」按钮，或点击列表操作列「编辑」，弹出对话框。

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| 市场名称 | 下拉选择（必填） | 选择所属市场；编辑时不可修改 |
| 解冻原因 | 文本输入（必填） | 自定义原因文案；编辑时不可修改 |
| 解冻有效期 | 单选 | 关闭（无限制）/ 开启 |
| 时长设置 | 步进器 | 仅「开启」时显示，分为「天」和「小时」两个维度可组合设置；天数和小时数同时为 0 时自动切换为「关闭」 |

**解冻有效期说明：**

- **关闭（无限制）：** 车辆完全解冻，无时间限制
- **开启：** 限定时间段内解冻，格式为 X 天 X 小时，超时后重新冻结

#### 删除确认

点击列表操作列「删除」后，弹出二次确认弹窗，确认后方可删除，防止误操作。

#### 关联说明

- 本页配置的解冻原因列表，直接影响车商在信车 APP 发起手动解冻申请时可选择的原因选项
- 不同市场的解冻原因相互独立，互不影响
- 删除某条原因后，历史已使用该原因的解冻记录不受影响

### 7.3 车辆列表 — 管控信息列新增标签展示

**需求说明：** 在「车辆管理 - 车辆列表」的**管控信息列**中，当车辆展示「已冻结」标签时，在其正下方紧跟展示冻结来源标签；若为手动冻结且填写了冻结原因，则在冻结来源标签下方再展示冻结原因标签。

**展示规则：**
- 不新增列，在原管控信息列内垂直堆叠展示
- 仅当存在「已冻结」标签时才展示冻结来源标签，未冻结车辆不展示
- 冻结原因标签：仅限 `freezeSource === 'manual'` 且 `freezeReason` 不为空时展示

**视觉结构：**
```
┌──────────────┐
│   已冻结      │  ← 原有标签（样式不变）
│   手动冻结    │  ← 冻结来源标签
│   车辆违规    │  ← 冻结原因标签（仅手动冻结且有原因时展示）
└──────────────┘
```

**冻结来源标签文案：**

| 冻结来源枚举值 | 标签展示文案 |
|------------|-----------|
| `manual` | 手动冻结 |
| `finance_pledge` | 金融质押冻结 |
| `contract` | 合同到期冻结 |
| `finance_ctrl` | 金融管控冻结 |

**冻结原因标签样式：** 橙色系标签（背景 `#fff7e6`，边框 `#ffd591`，文字 `#d46b08`），与冻结来源标签视觉区分。

**标签样式（冻结来源）：** 与冻结车列表中的冻结来源标签完全一致，参见 `B端-PC设计规范/标签组件规范.md`。

**接口需求：** 车辆列表接口返回数据中需新增以下字段：

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| `freezeSource` | string | 冻结来源枚举值；仅冻结车辆返回，未冻结为空 |
| `freezeReason` | string | 冻结原因文案；仅手动冻结且填写了原因时返回 |

## 八、异常与边界处理

| 场景 | 处理方式 |
|-----|--------|
| 切换冻结来源筛选，当前 Tab 被隐藏 | 自动回退至「已冻结」Tab |
| 金融质押冻结车辆，操作列不展示「车辆解冻」按钮 | 仅展示「查看详情」和「操作日志」 |

## 九、名词说明
